# Иконка Крест

`krest.png`, `krest.ico` и `relic/` — оригинальные материалы «KREST OS / Реликт»
из предоставленного владельцем набора `Krest-OS-Relic-final-pack.zip`.
Знак, металлическая палитра и надпись используются без перерисовки.

ICO содержит размеры от 16 до 256 пикселей. Для 16–64 px используются готовые
micro PNG; они сохраняют читаемость маленького знака. Файлы используются в окне, панели задач,
трее и меню; для них не требуется сборка EXE. Не удаляйте папку `assets` при переносе
исходников.
