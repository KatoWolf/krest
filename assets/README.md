# Иконка Крест

`krest.png` и `krest.ico` — адаптация присланного владельцем проекта изображения
креста с рубинами на фиолетовом фоне. Иллюстрация подготовлена генератором изображений
по этому референсу; PNG и ICO экспортированы из одной версии.

ICO содержит размеры от 16 до 256 пикселей. Файлы используются в окне, панели задач,
трее и меню; для них не требуется сборка EXE. Не удаляйте папку `assets` при переносе
исходников.
