# Независимый повторный аудит

Три отдельных агента проверили изменения относительно исходного `4c5be67`:
логику, безопасность/жизненный цикл сервисов и настоящий Tk-интерфейс.
Первый проход исправлений зафиксирован в `e8973bf`; этот документ описывает
дополнительные замечания и исправления после независимой проверки.

## Подтверждённые и исправленные проблемы

- `details()` мог получить KeyError при одновременной отмене restart. Теперь
  срок читается одним `get`, без блокирования UI на ожидании дочернего процесса.
- Неудачная остановка теряла принадлежность процесса. Теперь живой процесс
  остаётся учтённым, повторный запуск блокируется; stop_all пытается остановить
  остальные процессы и сообщает совокупную ошибку. Runtime закрывается в finally.
- Telegram читал необработанный JSON вместо расшифрованного snapshot настроек.
  Загрузка теперь использует ConfigManager; проверена подмена read_secret.
- Discord RESUME оставлял статус ошибки. Обработчик восстанавливает ready,
  не создавая повторных фоновых задач.
- Steam скрывал ошибки удалённой проверки последующим status. Ошибка сохраняется
  до успешного remote refresh. Первая ошибка объявляет разрешённую capability
  refresh без ложного ready; manager фильтрует capabilities по permissions.
- Числовой parser удалял недопустимую пунктуацию и неверно читал разряды.
  Цифровая и словесная грамматики теперь проверяются отдельно; неполные дроби,
  повторные разряды и неоднозначные сочетания отклоняются. Например,
  «один запятая двадцать пять километров» даёт 1250 м, «тысяча тысяч» — отказ.
- Decimal-контекст мог изменить округление возле половины копейки. Арифметика
  использует достаточную точность на всей операции. Независимые 2000 сравнений
  с Fraction прошли (сообщение агента; это дополнительная проверка, не новый
  сохраняемый тестовый набор).
- Поиск показывал карточку, но оставлял найденное поле ниже viewport. Поисковая
  строка закреплена, конкретное поле прокручивается в видимую область;
  фокус и черновики сохраняются, callback отменяется при перестроении темы.
- При 150% обрезались кнопки голоса, security, заголовок и вкладки.
  Адаптивные строки исправлены. Независимо проверены 9 тем × 5 страниц:
  все 45 сочетаний помещаются по ширине, ошибок Tk нет.

## Доказательства и границы

`review-python312.xml` и `review-python313.xml` — финальные полные прогоны.
`independent-ui-review.json` — независимые измерения actual Tk.
Скрипт ревью сохранён как текст: это исследовательский журнал с локальными
путями; воспроизводимые продуктовые проверки находятся в tests/test_menu_polish.py.
27 PNG в docs/menu-review получены настоящим ImageGrab; два состояния ботов
явно подписаны как fixtures. Контактный лист содержит 20 выбранных снимков.

После повторной проверки исходные замечания закрыты. Это не доказательство
отсутствия всех дефектов. Реальные Windows API, микрофон, игра, аккаунты и EXE
не проверялись. Указанный GitHub Actions относится к предыдущим исходникам,
а не к этой локальной ветке. Установщик не объявляется готовым.
