# Проверка версии для запуска из исходников — 11 октября 2026

Установщик отложен по решению пользователя. Версия запускается через start.bat;
инструкция и сохранение пользовательских данных — в START_HERE_RU.md.
Временный push-триггер Windows installer для рабочей ветки удалён, ручной запуск
сохранён. main не изменялся, merge/release/deployment не выполнялись.

## Найденные и исправленные ошибки

- Тест срока действия ответа больше не зависит от времени работы runner:
  контролируемый monotonic clock, границы 119.999/120/120.001 секунд и будущая метка.
  Запрет удалённого чтения локального ответа сохраняется.
- Успешная контекстная отмена таймера завершает прежнюю тему разговора;
  «ещё» после действия больше не продолжает старый факт.
- Ошибка действия сервиса в интерфейсе снимается после нового снимка ядра с
  подтверждённым running/ready без ошибки. Старый снимок и unknown её не скрывают.

- Telegram Terminal подтверждает ready только успешным штатным get_updates,
  отражает ошибки polling и восстановление без добавления сетевых запросов.
- Лимит загрузки Terminal проверяется по metadata и фактическим байтам до записи;
  отсутствующий размер не позволяет записать файл больше 20 МБ.

что все возможности проверены на реальном оборудовании.

через gh получила Forbidden на прежнем API-маршруте; отдельного cancel action
в подключённых инструментах нет. Отмена не подтверждена. Новые сборки установщика
не запускались. Исторические отчёты сохраняют результаты своих ревизий.

загружает файл целиком в память; потоковый сетевой лимит этим изменением не введён.

а не с живым Telegram-аккаунтом.
