## Изменения

- Общий предел job — 300 минут. Внутренний предел компилятора — 180 минут,
  предел шага — 190 минут. Проверке выделено 25 минут, Inno Setup — 15 минут.
  Запас предназначен также для подготовки зависимостей, завершения процессов и
  выгрузки диагностики. Он не гарантирует завершения тяжёлой компиляции.
- При внутреннем тайм-ауте на Windows вызывается taskkill /T /F только для PID
  запущенного процесса сборки. Частичный журнал и JSON состояния пишутся на диск;
  старая квитанция проверки дистрибутива аннулируется до компиляции.
- Сохраняется кеш Nuitka через отдельные restore/save actions. В ключ входят ОС,
  архитектура, Python 3.12 и хеш файлов зависимостей/сборщика; уникальный суффикс
  запуска позволяет сохранить обновление кеша. Standalone-каталог и квитанция
  проверки не кешируются. Выгрузка диагностики идёт раньше сохранения кеша.
- До компиляции сохраняются версии пакетов, Python, платформы, образа runner,
  число CPU и команда сборки. Окружение с секретами не выгружается. Отдельный
  preflight проверяет CPU PyTorch и наличие API PackageImporter/jit.load.
- Добавлен --show-memory. Частичные журналы, JSON состояния и SCons log собираются
  отдельно от XML Nuitka, который может отсутствовать до завершения компиляции.

Кеш MSVC clcache поддерживается самим Nuitka; pip cache не заменяет его.
См. [документацию Nuitka](https://nuitka.net/user-documentation/tips.html#caching-compilation-results).
Независимый аудит сверил флаги с исходным архивом Nuitka 4.3 (SHA-256
8b102c6bf30d9504e82e69674d396972729092b25cefa680e8fd05678fdfa30b).
Параллелизм оставлен 2: этот параметр относится к C-компиляции, а расход памяти
на реальном runner пока не измерен. Ускорение от кеша пока не измерено.

## Сохранение голоса и пределы доказательств

Сохранены torch-disable-jit=no, включение голосовых пакетов, загрузка моделей,
Vosk и синтез Silero в release smoke-test, проверка точного каталога навыков,
контроль SHA-256 дистрибутива перед Inno Setup. voice_engine использует
PackageImporter; отключать JIT или исключать модули torch без испытания готового
EXE необоснованно. Замены упаковщика и удаления голосовых функций нет.

Локально проверены обработка тайм-аута и сохранение журнала, статусы завершения,
команда уничтожения дерева Windows (mock), отклонение GPU-версии PyTorch
(тестовый модуль), YAML и параметры бюджета, полный набор Linux-тестов.
Это не проверка реального MSVC/taskkill, кеша GitHub, сборки Nuitka на Windows,
установки/обновления приложения, микрофона, проигрывателя или игры.
