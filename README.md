# Крест — голосовой помощник для Windows

Голосовые команды, управление музыкой и компьютером, напоминания, Steam,
Telegram/Discord, игровые гиды Dota 2 и Warframe. Боты и дополнительные темы
доступны после активации Premium в меню.

## Запуск исходников

Откройте **start.bat**. Помощник подготовит Python и зависимости, затем откроет
Крест. При первом запуске укажите имя. Микрофон подключается автоматически;
начните с «Крест, который час?».

## Обновления и меню

`start.bat` проверяет зависимости уже скачанной версии; `build-exe.bat` собирает
текущие исходники, включая новые модули и навыки. Они не скачивают код с GitHub.
Для копии через `git clone` используйте **update.bat**: завершите Крест через меню,
включая ядро в трее, и запустите файл. Обновление идёт из `origin/main`, только
вперёд и без удаления ваших правок; перед ним создаётся копия пользовательских
данных. Затем открывается запуск с проверкой зависимостей. Нужен Git for Windows.
ZIP без истории Git обновляйте новой распаковкой, сохраняя `model` и личные данные.
Готовый EXE обновляется новой ZIP-сборкой, а не батником для исходников.

Декоративные снег, кровь и частицы удалены вместе с настройками и фоновыми
таймерами. Старые параметры эффектов больше не используются. Игровой крест и
короткая подсветка кнопок сохранены. Во вкладке Premium есть **«Вставить и
активировать»**: скопируйте полный код; переносы строк убираются автоматически.

## Характер и разговор

Семь личностей имеют по 69 собственных реплик для 23 ситуаций и общий набор из
20 фактов. Ответы в одной теме чередуются без повторения до конца набора.
Стиль выбирается в профиле; голосовая модель остаётся прежней, интернет не нужен.
Это локальная база диалогов, а не свободно обучающаяся разговорная модель.

Попробуйте: «Крест, я вернулся», «у меня получилось», «меня всё бесит»,
«помоги сосредоточиться», «мне нужен перерыв», «вдохнови меня», «ты классная»,
«пожелай удачи в игре», «ты меня слышишь», «спокойной ночи», «до встречи».
Разговор о перерыве или сне сам по себе не запускает таймер и не выключает ПК.

## Яндекс Музыка и другие плееры

Текущий источник выбирается по медиасессиям Windows. Пауза, продолжение,
предыдущий/следующий трек работают через медиасессию. Лайк в настольной Яндекс
Музыке и Spotify ищется через доступные элементы окна: сначала панель текущего
трека, затем её кнопка отметки. Поддержаны дополнительные названия кнопок
коллекции и идентификаторы настольного приложения. После нажатия проверяются
состояние отметки и неизменность трека; повторный лайк не должен снимать отметку.

Доступ к кнопкам выполняется в отдельном короткоживущем процессе с лимитом
ожидания 20 секунд. Зависший помощник доступа завершается отдельно от ядра.

Для лайка разверните окно плеера с видимой нижней панелью. Крест запрашивает у
Electron дерево доступности без перезапуска приложения. Если приложение не
отдаёт подписи или состояние кнопок, действие завершается с объяснением:
координаты и глобальные горячие клавиши наугад не используются. «Музыка →
Проверить доступные команды и лайки → Диагностика плеера» показывает найденный
источник и кнопки, ничего не нажимая. Совместимость конкретной версии плеера
проверяется на Windows с запущенной музыкой.

## Голос: просто положите папку model рядом с программой

Поддерживаются оба варианта:

```text
Крест/
  main.py                  # или Krest.exe в готовой сборке
  model/
    am/final.mdl
    conf/model.conf
    model_silero.pt         # если есть файл голоса Silero
```

или распакованная модель внутри `model/vosk-model-small-ru-.../`. Крест ищет
модели до трёх уровней вложенности в `model`, `models`, `voice`; в EXE-версии
проверяет папку рядом с EXE независимо от рабочей папки запуска. Файлы Silero
`model_silero.pt`, `silero.pt`, `v4_ru.pt`, `v3_1_ru.pt`, `v3_ru.pt` тоже находятся
внутри `model` автоматически. Сохранённый существующий путь имеет приоритет.

Vosk распознаёт речь, Silero озвучивает ответы. Если имеется только Vosk,
распознавание может работать без озвучки. Недостающие модели при разрешённой
автозагрузке скачиваются с официальных серверов; найденная лёгкая модель не
заменяется большой. При нескольких неоднозначных моделях выберите нужную в меню.
Оборванные или повреждённые файлы Silero не считаются готовой моделью. Озвучка
восстанавливается в фоне с повторными попытками; микрофон продолжает слушать.
В разделе «Голос» видны ход загрузки и конкретная причина ошибки.

Микрофон выбирается автоматически: сначала системный вход Windows, затем другие
доступные устройства. Крест подбирает частоту USB/Bluetooth-микрофона и переводит
звук в нужный для распознавания формат. Если вход перестал передавать данные,
Крест пробует следующий. При тишине из-за mute она показывает подсказку.
Кнопка **«Автоматически подключить микрофон»** сбрасывает старый выбор устройства,
включает адаптацию чувствительности и перезапускает подключение. Если Windows
запретила микрофон, кнопка рядом открывает параметры доступа для классических приложений.

## Собрать программу в EXE

**Дважды нажмите build-exe.bat.** На компьютере автора нужен Python 3.11/3.12 x64;
если его нет, сначала откройте `start.bat`. Скрипт создаёт отдельную среду сборки,
устанавливает CPU-зависимости и упаковывает приложение через PyInstaller.
Visual Studio, Nuitka и Inno Setup не требуются.

Результат: **dist/Krest/Krest.exe** и **dist/Krest-Windows-0.9.2.zip**.
Передавайте пользователю ZIP целиком. Каталог `_internal` содержит необходимые
библиотеки: его нельзя удалять или отделять от EXE. **Модели Vosk и Silero входят
в обычную сборку автоматически**, в папку `model` рядом с EXE. Отсутствующие модели
скачиваются при сборке; если подготовка или синтез не удались, новый ZIP не создаётся.
Пользователю Python и загрузка моделей для этой сборки не нужны. Архив нужно сначала
полностью распаковать, затем запускать `Krest.exe` из распакованной папки.
Предыдущая сборка при повторном запуске сохраняется в `dist/Krest-previous-*`.

Дополнительные параметры для автора:

```bat
build-exe.bat --protect
build-exe.bat --protect --license "C:\путь\лицензия-pyarmor.zip"
build-exe.bat --without-models
```

Старый параметр `--with-models` поддерживается, но больше не требуется.
`--without-models` создаёт специальный облегчённый ZIP с пометкой `online-setup`:
ему нужен интернет при первом запуске. Для передачи друзьям используйте обычную сборку.

Обычный режим прячет Python-модули внутри пакета, но **байткод можно извлечь**.
`--protect` применяет PyArmor: собственный код обфусцируется и выполняется через
защитный runtime. Это затрудняет анализ, но не гарантирует полной секретности.
Для размера этого проекта может понадобиться лицензия PyArmor; при ограничении
лицензии или ошибке защиты сборка прекращается без незащищённой подмены.
PyTorch и прочие сторонние библиотеки упаковываются в готовом виде.

В сборку не копируются тесты, отчёты, Git, исходники проекта в виде открытых `.py`,
пользовательские настройки, сессии ботов и приватные ключи. После упаковки автоматически
проверяются загрузка команд, отдельный процесс ядра, импорт голосовых/сервисных
библиотек и настоящий синтез Silero с загрузкой Vosk. Проверка моделей запускается
из чистого профиля без их скачивания. Она не отправляет сообщения и не обращается
к микрофону или динамикам; проверка конкретной гарнитуры выполняется на компьютере пользователя.

GitHub: **Actions → Windows EXE** создаёт обычную сборку без PyArmor. Скачивайте
артефакт **Krest-Windows-EXE** только из успешного запуска. Наличие скрипта сборки
не означает готовый EXE. Защищённую версию собирайте локально со своей лицензией.
Пока репозиторий публичен, исходники доступны на GitHub независимо от упаковки EXE.

## Полезные команды

- Музыка: «переключи трек», «переключить трек», «смени песню», «поставь следующий трек»,
  «переключи на предыдущий трек». Слово «Крест» нужно перед первой командой.
- «Крест, выключи микрофон в Дискорде», «замуть меня в Дискорде».
- «Крест, включи микрофон в Дискорде», «размуть меня в Дискорде».
- «Крест, проверь микрофон в Дискорде» — проверить состояние без переключения.
- «Сделай скриншот», «открой скриншоты».
- «Открой сводку по миру», «скрой сводку», «что мне делать в игре» — Warframe.
- «Варфрейм план на тридцать минут», «варфрейм где фармить нейроды».
- «Запусти доту с гидом», «сводка матча», «когда руны», «убили Рошана».

Микрофон управляется через кнопку самого настольного Discord в Windows: токен,
подключение бота и Premium не требуются. Крест продолжает слышать команды; системный
микрофон не отключается. Повторное «выключи» оставляет мут включённым, повторное
«включи» оставляет микрофон включённым. Проверяется состояние кнопки, а не передача
звука собеседникам: серверный мут, отсутствие канала и режим «по нажатию» остаются
настройками Discord. Поддерживаются русские и английские названия кнопок.
Для свёрнутого/скрытого окна Крест временно показывает его без активации и возвращает
прежнее состояние. Если Discord не предоставляет доступ к кнопке, команда сообщит
об этом; откройте главное окно Discord и повторите проверку. Другие приложения
и браузерная версия Discord этим навыком не управляются.

Для музыки учитываются конкретные ошибки лёгкого Vosk: «креси с ключи трек»,
«крест прикручивать трек». Исправления действуют только на целую короткую команду;
они видны в истории распознавания и в кнопке «Разбор команды». Обычный режим Vosk
с оценкой уверенности каждого слова, модель и голос остаются прежними.
Разговорные формы работают для всего каталога: «можешь пожалуйста сделать скриншот»,
«открыть проводник», «поставить таймер на пять минут». При неизвестной фразе Крест
сравнивает слова и звучание с командами включённых навыков, включая импортированные.
Ошибки пробелов вроде «скрин шот» также учитываются. Числа и текст параметров
не подменяются похожим примером из справочника.

Однозначные исправления для ограниченного набора простых действий выполняются сразу.
В остальных случаях Крест уточняет одну команду или предлагает два варианта:
ответьте «Крест, да», «Крест, первое», «Крест, второе» либо «нет». Уточнение действует
25 секунд. Случайное «да» без обращения действие не запускает. После успешной
подтверждённой команды исправление сохраняется локально в **Дела и сценарии → Память**,
категория «Исправление»; его можно отредактировать или удалить. Для исправленных
команд закрытия, выключения, удаления и сторонних функций уточнение сохраняется.
Это обработка языка команд, а не обучение новой голосовой модели; сильный шум
и совсем другое распознанное предложение могут потребовать повторения.

При неизвестной голосовой команде
длинные подсказки остаются в меню; вслух — короткая просьба повторить не чаще раза
в десять секунд после обращения. Неизвестные фразы без обращения в окне продолжения
не озвучиваются. Во время игры успешное управление музыкой подтверждается «Готово».

Warframe определяется автоматически. Сводка появляется под игровым крестом;
для окна поверх игры используйте оконный режим без рамки. OCR распознаёт несколько
известных экранов, не противников и не весь игровой мир. Экспериментальный маршрут
записывает до минуты клавиш движения и повторяет один раз после подтверждения.
Esc, F8, движение мыши, смена окна или «верни управление» останавливают повтор.
Самостоятельный AFK-бой не реализован.

## Автоматическое обучение Warframe

При обнаружении Warframe Крест автоматически собирает локальные показы и учится
узнавать несколько знакомых экранов. Команда для начала не нужна. Профиль для
первого сценария: **Аполлон, Луа, реликвии Акси, Валькирия Прайм**; выбранный узел,
экипировка и полученная добыча в игре пока не проверяются.

В **Warframe → Обучение** отображаются примеры, статистика нажатий, знакомые
экраны и совпадения визуальной памяти с новым OCR. Переключатель отключает
автоматический сбор; кнопка остановки завершает текущую запись до следующего
запуска игры. Бирюзовый крест «Запоминаю» обозначает активную запись.
«Чему научилась в варфрейме» или «как идёт фарм» открывает отчёт под крестом.

Записывается только активное окно Warframe: один JPEG до 1024×576 раз в пять
секунд и изменения ограниченного набора игровых клавиш. При сворачивании игры
захват приостанавливается. Направление камеры, положение врагов и смысл каждого
нажатия эта запись не восстанавливает. Визуальная память использует маленькие
образцы, требует двух согласованных OCR-наблюдений и не обучается на собственных
догадках. Её предположение не запускает никаких игровых действий.

Автоматические записи делятся на отрезки до 20 минут и продолжаются, пока игра
открыта. Старые автоматические файлы заменяются в пределах 512 МБ, статистика
хранится для последних 100 показов. Ручные показы и посторонние файлы не удаляются;
если они занимают весь лимит, запись остановится с сообщением. Данные находятся
в `warframe_training/` и `warframe_visual_memory.json` внутри папки данных Крест,
не публикуются в Git и не отправляются на сервер. Кадры могут содержать видимый
игровой чат. «Открыть записи» позволяет просмотреть и сохранить нужные показы.

Необязательные команды: «начни показ аполлон» — отдельная сохраняемая запись;
«варфрейм метка ключ / проводник / демолист / защита / провал / награда / эвакуация»
— пояснение события; «закончи показ варфрейм» — остановка и сохранение отчёта.

**Обучение сейчас ограничено памятью экранов и сбором примеров.** Самостоятельный
выбор миссии, перемещение по случайной карте, поиск демолиста, бой и эвакуация
не обучены и не проверены. Число кадров не считается процентом готовности автопилота.

Dota: Крест находит библиотеки Steam и создаёт свой файл GSI с резервной копией
старого. «Играть с гидом» передаёт параметр `-gamestateintegration`. После первой
настройки перезапустите уже открытую игру. Старые выключенные настройки остаются
выключенными; включите автоматическую связь на странице Dota при необходимости.
Тайминги игровых событий требуют сверки с текущим патчем.

## Боты и данные

**Discord · мой аккаунт** — токен личной сессии, отдельное включение автоответов
и обновления вашего статуса. **Discord · серверный бот** — Bot Token из Developer
Portal, список серверов и текстовых каналов, проверка прав, настройка активности
и отправка сообщений от имени бота. Приглашение на сервер открывается кнопкой
после подключения. Привилегированные Message Content / Members intents не нужны.
Отправка выполняется только по нажатию; при потере подтверждения проверьте канал
перед повтором. Для больших аккаунтов панель показывает первые 50 серверов и
60 доступных текстовых каналов выбранного сервера.

В полях ключей есть кнопка «Вставить», контекстное меню по правой кнопке,
Ctrl+V и Shift+Insert. Сочетания клавиш работают и в русской раскладке Windows.
Кнопка «Вставить» заменяет значение целиком, повторное нажатие не дублирует ключ.

Telegram User: введите API ID, API Hash и полный телефон с кодом страны,
нажмите «Получить код», затем введите код и нажмите «Войти». При включённой 2FA
появится отдельное окно пароля. Неверный код или пароль можно исправить без
повторного запроса кода. После успешного входа нажмите «Запустить».
Обновление описания Telegram включается отдельно; исходный текст профиля
не меняется при обычном подключении. Статус «Подключён» означает подтверждённую
готовность сервиса; работающий процесс без подключения показывает «Подключение…».

Личная сессия Discord использует неофициальные
интерфейсы; Discord запрещает self-bots, возможна блокировка. Статусы и автоответы
включаются отдельно. Telegram и Discord используют общие стили ответов с
предпросмотром, ограничением частоты и настройкой удаления. Токены вводите только
в локальном меню. В Windows используется хранилище учётных данных.

Данные EXE-версии: `%LOCALAPPDATA%\Krest\Data`. Скриншоты — подпапка `screenshots`;
