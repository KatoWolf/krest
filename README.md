# КРЕСТ — Python-исходники

Проект объединяет основное ядро, меню, голос, Telegram/Discord и все присланные
модули навыков. Сборка EXE, установщик и пакет приложения не создаются.

## Запуск

Рекомендуется Python 3.11–3.12 с Tkinter (на Windows входит в обычную установку).

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python main.py
```

На Linux используйте `python3 -m venv .venv`, `.venv/bin/python` и графический сеанс.
Tkinter и PortAudio устанавливаются средствами системы. Для разработки и тестов:

```sh
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python main.py --check
.venv/bin/python -m pytest -q
```

`--check` проверяет загрузку всех модулей без запуска микрофона, ботов и GSI.
`--command "посчитай 12 * 8"` выполняет одну команду без окна.
Таймер, созданный через CLI, сохраняется; для его срабатывания нужно запустить GUI
или консольное ядро. Импорт `main` не создаёт второй экземпляр состояния.

Существующий `start.bat` остаётся обычным скриптом запуска исходников.

## Меню

- **Обзор:** текстовая команда, ответ, последние события, включение/выключение голоса.
  Стрелки вверх/вниз перебирают историю ввода и возвращают незавершённый текст; `Ctrl+L` переводит фокус на команду. `Ctrl+S` сохраняет настройки.
- **Голос:** уровень микрофона, пауза и уверенность распознавания, «Услышала → Поняла»,
  сохранение исправлений, тестовая запись, калибровка фона и словарь произношения.
- **Музыка:** найденные медиасессии, автоматический выбор плеера и прямые команды.
- **Навыки:** каталог 116 команд, поиск по описанию и ключевым словам, примеры,
  состояние платформы и выключение отдельных модулей. Двойной щелчок подставляет
  команду без её автоматического выполнения. Доступна перезагрузка навыков.
- **Таймеры:** установка таймеров и будильников, остаток времени, отмена выбранного,
  дни недели, откладывание и история выполнения. Работают и без голосовых моделей.
- **Сценарии:** редактор последовательностей команд, программ, пауз и режимов.
- **Уведомления:** сохраняемая история, группировка повторов и режим озвучки.
- **Нагрузка и файлы:** профили фоновой работы, CPU/RAM, предпросмотр сортировки,
  журнал перемещений и возврат последней партии.
- **Telegram:** управление Terminal и User-мостом.
- **Steam / CS2:** библиотека, AppID, инвентарь, ограничения обмена и события.
- **Мой Discord:** личная активность через Rich Presence.
- **Discord-бот:** отдельный обычный бот с автоответами.
- **Скрипты и мосты:** подключение своих Python-сервисов и проверка уведомлений.
- **Dota 2:** параметры GSI, отдельный запуск и остановка сервера, создание игрового
  конфига, ручной старт матча, таймер Рошана и состояние подключения.
- **Настройки:** профиль, семь тем (четыре в Premium), обращение, время ожидания команды, громкость,
  микрофон, пути моделей, город погоды, трей, автозапуск с Windows и индикатор речи.
- **Журнал:** события ассистента и вывод отдельных интеграций. Логи процессов
  ограничены по размеру, известные токены скрываются до записи на диск.
- **Premium:** активация кодом, статус доступа, палитра тем и проверка модулей.

Настройки не теряются при переключении страниц и смене темы. Кнопка сохранения
отмечает несохранённые изменения. Ошибки числовых полей не записываются в конфиг.
Повреждённый `config.json` сохраняется в резервную копию `.broken-*` перед заменой.

## Первый запуск и личность

При первом запуске меню появляется знакомство с Крест: введите имя обращения и
выберите стиль общения — дружелюбный, краткий или живой. Это локальный профиль;
сетевого аккаунта, пароля и проверки личности здесь нет. До завершения знакомства
автозапуск ботов и фоновых задач не начинается. После сохранения профиль больше
не спрашивается. Имя и стиль можно изменить в настройках.

В старых конфигах без профиля прежние имена-заглушки «Игорь», «КатоВульф» и
`KatoWolf` очищаются; остальные настройки сохраняются. Уже созданный новый профиль
с таким именем не сбрасывается. Новая установка не содержит предустановленного имени.

Добавлены команды `привет`, `спасибо`, `кто ты`, `как дела`, `как меня зовут`,
`поддержи меня`, `расскажи шутку`, `план на сегодня`. Ответы выбираются из локального
набора с учётом имени и стиля; одинаковое приветствие не повторяется подряд, кроме
краткого режима. Это набор сценариев общения без языковой модели. Утренний сценарий
показывает реальную сводку системы и ежедневных дел, не обещая запуск ненастроенных программ.

## Музыка: автоматический выбор и прямое управление

На Windows обновите зависимости:

```powershell
.venv\Scripts\python -m pip install -r requirements-windows.txt
```

Запустите трек в настольной Яндекс Музыке и откройте **Музыка**. Крест найдёт
источники через Windows SMTC. При единственном играющем плеере выбирается он,
даже если Windows считает текущей другую, приостановленную сессию. При нескольких
играющих источниках предпочтение получает текущая медиасессия Windows; неоднозначный
выбор требует указать плеер в меню. **Выбрать источник** закрепляет его AppID,
**Автовыбор** возвращает автоматическое определение. Выбор сохраняется между запусками.

Команды проверяют источник заново при каждом вызове. Если закреплённый плеер
закрыт, Крест сообщает об этом и не переключается незаметно на другой.

- `пауза` всегда ставит на паузу; повторная команда не включает музыку.
- `продолжи музыку`, `следующий трек`, `предыдущий трек` адресуются медиасессии.
- `перемотай вперед` / `перемотай назад` перемещают позицию на десять секунд,
  ограничивая её началом и концом трека. Глобальные стрелки клавиатуры не используются.
- `что играет` сообщает источник, исполнителя, название и состояние;
  `длительность трека` — позицию, длительность и остаток.
- `громкость на двадцать пять`, `громче на десять`, `выключи звук`, `включи звук`
  управляют системной громкостью через CoreAudio. Это громкость компьютера, не отдельного приложения.

SMTC не имеет универсальной команды «Нравится». Для настольных Яндекс Музыки и
Spotify добавлен отдельный адаптер Windows UI Automation. Он ищет процесс плеера,
подтверждает название текущего трека в его окне, находит единственную доступную
кнопку по её доступному имени и проверяет состояние после нажатия. Уже установленный
лайк повторно не снимается. Команды: `поставь лайк`, `убери лайк`, `поставь дизлайк`.

Для первого теста откройте экран текущего трека в плеере. При нескольких одинаковых
кнопках, скрытом окне, отсутствии доступного имени/состояния, недостаточных правах
или неподдерживаемом приложении Крест сообщает причину. Если действие отправлено,
но плеер не подтвердил изменение, это показывается как неподтверждённый результат.
У браузерных вкладок лайки пока не подключены; базовые команды работают, если браузер
предоставляет медиасессию. Полное управление любым плеером без его поддержки невозможно.

Проверка на вашем Windows:

1. Включите трек Яндекс Музыки, откройте «Музыка» и проверьте название источника.
2. Дважды скажите `пауза`: музыка должна оставаться на паузе. Затем `продолжи музыку`.
3. Откройте в браузере видео, поставьте его на паузу и проверьте `следующий трек`:
   при играющей Яндекс Музыке команда должна адресоваться ей.
4. Проверьте перемотку, лайк и повторный лайк на экране текущего трека.
5. Если кнопка недоступна, запишите текст ошибки и версию приложения: нужен адаптер
   под фактические доступные элементы этой версии, а не подбор глобальных клавиш.

В облаке проверены выбор источника, адресация, пауза, перемотка и логика кнопок на
подменённых WinRT/UIA-объектах. Настоящая Яндекс Музыка и Windows здесь не запускались.

## Обычная версия и Premium

| Возможность | Обычная | Premium |
| --- | --- | --- |
| Голос, музыка, локальные навыки и профиль | Да | Да |
| Напоминания и автоматическая сортировка | Да | Да |
| Сценарии, контекст команд, уведомления и профили нагрузки | Да | Да |
| Три исходные темы | Да | Да |
| Telegram, Discord, Steam-монитор, свои скрипты и мосты | Нет | Да |
| Arctic Light, Ocean Blue, Copper Night, Rose Quartz | Нет | Да |

Во вкладке **Premium** вставьте выданный автором код и нажмите **Активировать**.
Код подписан Ed25519; замены `is_premium` в JSON недостаточно. Он проверяется
локально по `license_public_key.pem`. Поддержаны бессрочный доступ и срок действия.
Проверка стоит на запуске сервисов, отправке команд мостам, авторизации Telegram
из меню и прямом запуске встроенных ботов. Сами исходники ботов остаются в репозитории.
При отключении или истечении Premium работающие сервисы, запущенные меню, останавливаются,
а премиальная тема заменяется базовой. Данные профиля, настройки и ключи ботов сохраняются.
Отключение не отзывает ранее выданный код: его можно снова активировать.

Для автора подготовлен отдельный **набор издателя**: закрытый ключ и собственный
бессрочный код. В GitHub хранится только открытый ключ. Закрытый ключ нельзя включать
в дистрибутив или исходники для пользователей. Сохраните его резервную копию.
Для выпуска новых кодов с этим ключом:

```powershell
.venv\Scripts\python tools\license_admin.py issue --private "D:\KrestIssuer\krest.private.pem" --days 30 --output "D:\KrestIssuer\customer-code.txt"
```

`--days 0` выдаёт бессрочный код. Утилита не перезаписывает существующие ключи и файлы
кодов. Если создаёте собственное независимое издание, сначала выполните
`tools/license_admin.py init --private <закрытый-файл-вне-проекта> --public license_public_key.pem`.
Смена открытого ключа делает ранее выданные другим ключом коды недействительными.

Это офлайн-лицензирование: коды переносимы между устройствами, срок зависит от часов
компьютера. Серверный отзыв, одноразовая активация и учёт устройств не реализованы.
Открытый Python-код можно изменить, поэтому этот механизм не является защитой
от модификации программы. Оплата и магазин в приложение не добавлены.

## Что проверено в навыках

Все зарегистрированные ключевые фразы и примеры проверяются на попадание в свой
навык. Полные шаблоны с параметрами учитывают конкретность команды: таймер больше
не перехватывается общим запуском игры, а поисковый запрос не выполняет упомянутое
внутри него действие. Явное отрицание не запускает положительную команду.

Дополнительно исправлены повторное включение тихого режима, возврат озвучки,
пересечение команд аптайма, сохранение шаблонов, ограничение ожидания GPU-утилиты,
отображение ошибок после промежуточного голосового ответа, определение неудачного
запуска игры, Win+M для сворачивания и открытие уведомлений Windows 11.
`проверь зависшие` теперь только перечисляет зависшие окна; завершение выделено
в `закрой зависшие`. Проверка загрузки и тесты не подтверждают работу каждого
системного вызова и стороннего сервиса на настоящем компьютере. Тайминги Dota
по-прежнему нужно сверять с текущим патчем игры.

## Голос и Windows

```powershell
.venv\Scripts\python -m pip install -r requirements-voice.txt
.venv\Scripts\python -m pip install -r requirements-windows.txt
```

Вторая команда добавляет Windows-зависимости для информации о медиасессиях и точной
системной громкости, а также UI Automation для кнопок настольного плеера.
Без этих пакетов Крест сообщает о недоступности управления; нажатия в случайное
активное окно не отправляются.

Русская модель Vosk: https://alphacephei.com/vosk/models — распакуйте её и выберите
папку в меню (внутри должны быть `am/` и `conf/`). Русская Silero TTS v4:
https://github.com/snakers4/silero-models — получите совместимый пакет `.pt` из
официального проекта и выберите его в меню. PyTorch PackageImporter выполняет код
модели, поэтому используйте доверенные файлы. Автозагрузка кода из сети выключена.

Сначала сохраните пути, затем включите голос. Можно сказать «крест время» либо
«крест», дождаться «Слушаю» и назвать команду в течение заданного интервала.
После `усни` микрофон продолжает распознавать обращение `крест проснись`.
Тихий режим отключает озвучку, сохраняя текстовые ответы. Индикатор `guikrest.py`
работает в главном Tk-потоке и ничего не запускает при импорте.

После изменения пути модели или микрофона выключите и включите голос.
Автозапуск Windows добавляет только запись `KrestAssistant` в раздел Run текущего
пользователя; отключение переключателя удаляет эту запись.

## Настройка речи на i3-9100F / 16 ГБ / GTX 1050 Ti

Текущие Vosk, Silero, голос `xenia` (резервный `kseniya`) и звуковой эффект сохранены.
Новые модели не нужны; распознавание и синтез остаются локальными, на CPU.
Модели загружаются только при включении голоса. По умолчанию синтез использует
два потока CPU; можно выбрать 1–4. Это ограничение параллелизма, а не гарантия
фиксированного процента нагрузки: замеры на компьютере владельца ещё нужны.

Первая проверка во вкладке **Голос**:

1. Выключите голос и дождитесь статуса «Голос остановлен». Выберите микрофон по имени
   или индексу; список устройств есть в настройках. Пустое поле использует системный.
2. Нажмите **Измерить фон** и помолчите пять секунд. Нажмите **Применить измеренный
   порог**, затем **Сохранить изменения**. Это подбор порога начала речи по громкости,
   а не удаление шума из записи. Слишком высокий порог может пропустить тихую речь.
3. Нажмите **Записать 5 секунд**, произнесите обычную фразу и прослушайте запись.
   Проверьте выбранное устройство, громкость и перегрузку. Запись хранится только
   в памяти, заменяется следующей записью и не отправляется в сеть.
4. Включите голос и скажите «Крест, который час?». В карточке **Что услышала и поняла**
   видны распознанная фраза, команда после подстановок, оценка Vosk и результат.
5. Если команда распознана неверно, введите существующую правильную команду и нажмите
   **Запомнить исправление**. Крест сохранит точное соответствие фраз в «Мои команды».
   Нажатие не выполняет действие; повторите фразу для проверки. Это словарь команд,
   а не обучение акустической модели вашему голосу.

По умолчанию Крест завершает фразу после **700 мс** тишины. Если вы делаете паузы
внутри команды, попробуйте 900–1200 мс; уменьшение паузы сокращает ожидание, но может
обрезать фразу. Входная очередь ограничена одной секундой звука; при переполнении
незавершённая фраза сбрасывается, чтобы не выполнять команду из устаревших фрагментов.
В меню видны число пропущенных блоков и промежуточный текст распознавания.

Порог уверенности по умолчанию **60%**. При меньшей средней оценке слов Крест просит
повторить команду и не передаёт её навыку. Оценка Vosk не гарантирует правильность;
она не заменяет проверку того, что было услышано. Обращение сравнивается с целым
первым словом: «лес», «тест», «кресло» и похожие слова больше не заменяются на «Крест».
При проблемах с обращением нажмите **F8** или **Слушать команду** и произнесите команду
без имени в течение настроенного времени ожидания.

**Escape** и **Прервать ответ** останавливают воспроизведение и очищают ожидающие
ответы. Если синтез уже начался, его вычисление завершится, но отменённый звук не
будет проигран. F8 и Escape действуют, когда активно окно Крест. Во время озвучки
распознавание приостановлено, чтобы Крест не выполняла собственные слова; голосового
прерывания ответа и акустического эхоподавления пока нет. Для работы рядом с колонками
помогут гарнитура и снижение громкости.

Поддержаны, например, «сделай музыку потише», «поставь музыку на паузу»,
«открой контру», «напомни выпить воды через пять минут». Названия игр требуют
соответствующей игры в библиотеке. Подстановки применяются к команде целиком;
содержимое напоминаний не заменяется общим списком похожих слов.

В словаре **Произношение слов** задайте название и чтение, например
`Discord` → `диск+орд`: плюс перед ударной гласной. Добавьте запись и сохраните
настройки; **Произнести слово** позволяет проверить её при включённом голосе.
Время и распространённые единицы разворачиваются перед синтезом. Длинные ответы
по умолчанию озвучиваются сокращённо, а полный текст остаётся в меню. Переключатель
звукового эффекта позволяет отключить обработку тембра; исходно эффект включён.
Изменение устройства, моделей и числа потоков требует выключения и включения голоса;
остальные настройки применяются после сохранения.

Тесты обработки речи используют искусственный PCM и подменённые аудиоустройства и
модели: проверены паузы, предварительный захват начала фразы, переполнение, отмена
синтеза, порог уверенности, исправления, сохранение настроек и ошибки микрофона.
Настоящие модели и микрофон в облаке не запускались. Проверяйте слышимость и задержку
на своём компьютере описанными выше шагами.

## Telegram / Discord / Steam

Telegram Terminal требует токен BotFather и положительный числовой ID владельца.
Обработчики принимают команды только от этого ID. Сохраните настройки и нажмите
«Запустить». Бот содержит удалённый терминал, передачу файлов, управление питанием
и рабочим столом: доступ к токену означает доступ к этим возможностям.

Telegram User требует API ID/API Hash с my.telegram.org и номер телефона. Используйте
кнопки запроса кода и входа; пароль 2FA вводится отдельным диалогом. Перед авторизацией
панель останавливает свой экземпляр моста, чтобы освободить файл сессии. После входа
запустите мост кнопкой. Сервис не отправляет сообщения во время автоматических тестов.

Discord использует обычный **токен бота**, а не токен личного аккаунта. В Developer
Portal включите Message Content Intent. Автоответы работают в личных сообщениях
боту. Неверный токен/недоступные intents теперь завершают процесс с понятной ошибкой.

Steam обслуживают новый процесс `steam_bot.py`, модуль `steam_service.py` и команды `skills/steam.py`. Старые ручные команды Telegram Terminal также сохранены. Для TGT-команды скачивания аудио опционально нужны yt-dlp и
FFmpeg. Прежний диалог через Ollama удалён: команды и автоответы работают по правилам, без LLM.

«Запущен» в меню означает живой процесс, а не подтверждённую авторизацию сервиса.
Смотрите журнал и проверяйте ответ в соответствующем клиенте. Боты не запускаются
автоматически при открытии меню. Изменение токена требует перезапуска бота.

## Dota 2

Импорт навыков не открывает порт и не меняет файлы игры. Сервер слушает только
`127.0.0.1`, по умолчанию порт 3000; неверные и слишком большие запросы отклоняются.
Запустите сервер из меню, затем при необходимости нажмите «Настроить GSI».
Существующий отличный конфиг не перезаписывается молча. После настройки перезапустите
игру. Автоматическое включение гида требует отдельного переключателя.

Без GSI можно использовать `матч начался`. Время поступившего GSI имеет приоритет;
при потере связи оно не продолжает бесконтрольно увеличиваться. Остановка сервера
освобождает порт и завершает принадлежащие ему потоки.

Правила игровых событий сохранены из присланного `gid.py`. Их соответствие текущему
патчу Dota не проверено; при обновлении игры интервалы следует сверить.

## Устройство кода

`main.py` — точка входа. `app_runtime.py` — общий обработчик команд, планировщик и
очередь событий. `app_state.py` — состояние и сохранение таймеров. `skill_manager.py`
— обнаружение, выбор команд и диагностические результаты. `voice.py` — лёгкий
интерфейс вывода, `voice_engine.py` — лениво загружаемый Vosk/Silero.
`welcome_gui.py` — меню; `configuration.py` — валидация настроек;
`integrations.py` — управление дочерними процессами и их журналами.

Текстовые команды и голос используют один реестр и одно состояние. Долгие команды
выполняются в рабочем потоке, таймеры — в отдельном планировщике. Все обращения к
виджетам и диалоги проходят через главный Tk-поток. Озвучка последовательная.

`assistant_state.json` хранит таймеры, будильники, ежедневные дела и непрочитанные напоминания. При пропущенном времени
будильник срабатывает после возобновления работы, а время в прошлом при установке
назначается на следующий день. Секундомер использует монотонные часы и не сохраняется.
Когда программа закрыта, уведомления не выполняются. Очередь уведомлений от ботов
хранится в SQLite, ограничена 100 событиями и сроком пять минут.

`config.json`, модели, сессии, пользовательские данные и журналы исключены из Git.
Ключи хранятся локально без шифрования. Резервные копии конфига также могут содержать
ключи. Не включайте эти файлы в публикуемые исходники.

## Проверки и границы проверки

Тесты проверяют загрузку навыков без побочных действий, выбор конкурирующих команд,
числительные, ошибки времени, таймеры, перезапуск состояния, пробуждение, очистку
временных файлов на тестовой папке, ограничения калькулятора, сообщения об ошибках,
GSI через реальные локальные HTTP-запросы, процессы, SQLite и меню.
Дополнительные проверки покрывают ежедневные дела, откладывание, восстановление после
ошибок записи, свои фразы, историю команд, отмену очереди и сортировку на временных
тестовых папках. Текущий результат проверки в облаке: 156 тестов пройдено, 116 навыков
загружаются без ошибок; Ruff и проверка зависимостей также проходят.

GUI-тест требует `DISPLAY` в Linux; без него он явно пропускается. В облаке проверяется
на виртуальном X-дисплее. Реальные входы в Telegram/Discord, голосовые модели,
микрофон, Win32-команды, трей и автозапуск Windows требуют проверки на компьютере
владельца. Внешние сайты погоды/новостей/валют могут быть недоступны из облачной сети.
В таком случае команда возвращает ошибку; курс валют не подменяется выдуманным.


## Ежедневные задачи и свои команды

На странице **Таймеры** заполните «О чём напомнить». Для разового напоминания
задайте длительность, для повторяющегося — время, дни недели и нажмите «Сохранить расписание».
Ежедневные дела сохраняются в `assistant_state.json`; их можно отменить в общем
списке. Сработавшие напоминания остаются в отдельном списке до кнопки «Готово»
или «Отложить» с выбранной длительностью. Откладывание не отменяет расписание.

Примеры текстовых и голосовых команд:

- `крест напомни через пять минут выпить воды`
- `напомни через 1 час 5 минут: проверить духовку`
- `крест напоминай каждый день в девять утра сделать зарядку`
- `напоминай каждый день в 21:30 проверить завтрашние дела`

Крест должна быть запущена, в том числе в трее. Она не будит выключенный компьютер.
После перезапуска просроченное разовое напоминание появится в списке. Для ежедневного
дела показывается одно пропущенное срабатывание, а следующее назначается на ближайшее
время по местным часам компьютера. После смены часового пояса пересоздайте ежедневные
задачи: уже сохранённое ближайшее срабатывание имеет абсолютную отметку времени.

**Мои команды** содержит избранное, историю текущей сессии и свои фразы. Избранное
записывается локально в `favorites.json`, история ввода на диск не пишется. Двойной
щелчок только подставляет текст: выполнение требует Enter или кнопки.
В «Свои фразы» можно связать `пора отдыхать` с `таймер на двадцать минут`.
Сохраните настройки; затем фраза работает голосом и текстом. Это одна точная
подстановка без цепочек и генеративного ИИ. Своя фраза имеет приоритет над обычной
командой с таким же текстом; команда-цель должна быть существующим навыком.

Кнопка «Очистить очередь» отменяет только ещё не начавшиеся команды. Уже выполняющийся
навык продолжает работу. Под полем ввода показывается выполняемая команда и число
ожидающих. Для неизвестных команд предлагаются похожие доступные фразы; они не
запускаются автоматически. «Пожалуйста» в начале/конце команды можно опускать.

## Фоновая сортировка загрузок

### Предпросмотр и отмена

На странице **Нагрузка и файлы** можно посмотреть, куда будут распределены готовые
файлы, запустить сортировку вручную, открыть журнал и вернуть последнюю партию.
Предпросмотр не создаёт папки и журнал. Команды: `предпросмотр сортировки`,
`отмени сортировку`. Журнал `.krest-sort-history.sqlite3` хранится в папке загрузок.
Без него восстановить исходные пути автоматически нельзя.

Отмена проверяет SHA-256 содержимого и свободное исходное имя. Изменённые,
перемещённые файлы и занятые имена пропускаются с объяснением. Возвращённые файлы
не сортируются автоматически повторно, пока их размер или дата изменения прежние;
явная ручная сортировка доступна. Уже перемещённые файлы до появления журнала
не попадают в отмену. Прерванная операция может оставить две копии; единственная
копия не удаляется до успешного сохранения другой. При ошибках последнюю партию
можно повторно проверить после устранения причины.

### Автоматический режим

В **Настройки → Автосортировка загрузок** выберите свою папку, включите переключатель
и сохраните настройки. При следующих запусках Крест режим сохраняется. До первого
включения автоматические перемещения отключены. Сортировка работает отдельным
потоком и не задерживает команды и напоминания.

Проверка выполняется каждые 30 секунд. Файл переносится в соответствующую папку
`*_Krest`, когда его размер и время изменения стабильны минимум две минуты и он
не изменялся последние две минуты. Поэтому после включения есть задержка наблюдения.
Старые файлы в выбранной папке тоже сортируются. Вложенные папки, ссылки, скрытые
и незавершённые загрузки (`.part`, `.crdownload`, `.tmp` и др.) пропускаются.
Файлы без расширения остаются на месте. Одноимённые файлы получают номер, исходный
экземпляр не перезаписывается. При ошибке копирования оригинал остаётся на месте.
Изменившийся во время копирования файл будет повторно проверен позже.

Команда `рассортируй загрузки` использует ту же выбранную папку и проверку возраста
файлов, но без двухминутного периода наблюдения. Длительные приостановленные загрузки
без временного расширения могут выглядеть завершёнными: для таких программ выбирайте
отдельную папку. Отключение модуля «Состояние компьютера» также отключает фоновую
сортировку. Состояние видно в настройках; результаты и ошибки — в журнале.

## Обновлённые подключения и проверка голоса

У каждого бота отдельная карточка: состояние процесса, PID, время работы,
запуск/остановка/перезапуск и переход к журналу. «Настройка доступа» раскрывает
поля токенов и авторизацию. Во время операции кнопки блокируются. Ошибки запуска
показываются в карточке; секреты скрываются в сообщениях журнала.

В настройках кнопка **Проверить готовность голоса** показывает наличие зависимостей,
выбранные пути моделей, микрофон и обращение. Проверка не скачивает модели и не
подключается к ботам. Для проверки устройства используйте «Проверить аудиоустройства»,
затем включите голос. Vosk и Silero используются локально для распознавания/озвучки;
обработка команд не требует языковой модели или облачного ИИ.

## Идеи следующего этапа

1. Редактор сценариев «Работа / Игра / Сон»: несколько явно выбранных действий одной
   фразой, предварительный просмотр и остановка оставшихся шагов.
2. Расписание по дням недели и журнал выполнения ежедневных дел: отмечать не только
   прочтение напоминания, но и выполнение задачи.
3. Несколько сохранённых настроек микрофона: для гарнитуры, колонок и игры,
   с ручным переключением профиля.
4. Предпросмотр и отмена последней сортировки файлов с учётом файлов, изменённых
   после перемещения.
5. Настраиваемые игровые профили: громкость, режим уведомлений и запуск GSI для
   выбранной игры; справочник таймингов с привязкой к версии Dota.

Это предложения для следующего этапа, а не уже реализованные функции.


## Steam: настройка и возможности

1. Откройте **Steam / CS2**. Введите свой SteamID64 (17 цифр) и Steam Web API Key,
   полученный на https://steamcommunity.com/dev/apikey . Пароль Steam и Steam Guard
   Крест не запрашивает.
   SteamID64 и ключ должны относиться к одному аккаунту: предложения обмена API
   возвращает для владельца ключа.
2. При необходимости выберите папку Steam, содержащую `steamapps`. Оставьте путь
   пустым для поиска обычной установки. Дополнительные библиотеки читаются из
   `libraryfolders.vdf`.
3. Сохраните настройки и нажмите «Запустить» или «Обновить сейчас». Для обновления
   при каждом запуске Крест включите «Запускать вместе с Крест» и сохраните настройки.
4. При желании включите доставку событий себе в Telegram. Используются Bot Token
   и ID владельца из Telegram Terminal; сначала откройте диалог со своим ботом.
   Запуск самого Terminal для отправки этих уведомлений не требуется.

**Библиотека.** `GetOwnedGames` возвращает названия и AppID принадлежащих аккаунту игр,
которые доступны этому API. Крест объединяет их с локальными `appmanifest_*.acf`.
API может не перечислять некоторые бесплатные, семейные, скрытые игры или сторонние
ярлыки. AppID — идентификатор игры для `steam://rungameid/...`, не ключ активации.
Новые установленные игры обнаруживаются автоматически примерно за 30 секунд;
онлайн-библиотека проверяется по заданному интервалу (по умолчанию 15 минут).
Для неустановленной игры Steam может предложить установку. Кнопка обновления
ограничена одним запросом в минуту. Команды «запусти игру …» используют общий каталог.

**CS2.** Монитор читает публичный инвентарь `730:2` с пагинацией. В меню видны имя,
количество, доступность обмена и ожидаемая дата, если она явно указана Steam.
Предметы с `tradable=0` не обязательно находятся под временным запретом: часть предметов
нельзя обменивать вообще. Неизвестный срок не вычисляется из количества дней
`market_tradable_restriction`. Скрытые/защищённые предметы, которые Steam не выдаёт,
не входят в подтверждённый счётчик; это не гарантия полного внутреннего инвентаря.
Закрытый инвентарь через публичный endpoint получить нельзя.

**Оповещения.** После первой успешной проверки фиксируется исходное состояние.
Последующие проверки сообщают о новых играх, новых входящих предложениях, подтверждённом
переходе предмета из недоступного в доступный для обмена и снятии `EconomyBan`.
Исчезновение предмета из инвентаря не трактуется как снятие запрета. Истечение
ожидаемой даты само по себе не запускает уведомление «обмен доступен»: нужен новый
ответ Steam. Задержка обнаружения зависит от интервала проверки.
События идут в журнал/озвучку/трей Крест и, при включении опции, в Telegram владельцу.
Steam также сохраняет последние 100 событий. Неудачная Telegram-доставка отмечается
в журнале, автоматической повторной отправки нет.

**Обмены и ограничения.** Показываются входящие/исходящие активные предложения,
`EconomyBan`, время обновления и ошибки. API не даёт надёжной универсальной даты
окончания ограничения всего аккаунта. VAC/игровые баны также не равны запрету
обмена. Подтверждать Steam Guard, принимать/отправлять трейды, продавать предметы
или обходить ограничения этот модуль не умеет. Кнопка открывает страницу обменов Steam.

`steam_state.json` — локальный кэш, исключённый из Git. При временной ошибке сети или
частичном ответе инвентаря прежние данные остаются с прежней датой проверки и ошибкой.
Без ключей можно использовать локальную библиотеку. При закрытой программе проверки
не выполняются; режим трея и автозапуск позволяют оставить Крест работающей.

Команды: `библиотека стим`, `инвентарь кс`, `ограничения обмена`, `предложения обмена`.
Они читают последний кэш, не выполняя дополнительных запросов к Steam.

## Discord: личный аккаунт и обычный бот

На странице **Мой Discord** используется локальный Rich Presence через `pypresence`.
Создайте приложение на https://discord.com/developers/applications , скопируйте
Application ID, запустите настольный Discord, заполните текст активности и запустите
мост. Discord должен разрешать отображение активности. Статус обновляется каждые
20 секунд; при разрыве соединения мост пытается подключиться снова через 30 секунд.
При включённом переключателе используется состояние Крест/Dota из локального файла.

Rich Presence показывает активность личного аккаунта, но не меняет произвольный
custom status и не читает/отвечает на личные сообщения аккаунта. Discord не
предоставляет поддерживаемый API для такого автоответчика личного аккаунта;
self-bot с пользовательским токеном нарушает правила Discord. Этот проект не
реализует такой вход. Обычный бот вынесен на страницу **Discord-бот**: он отвечает
в своей личке, а не от имени вашего аккаунта. Это существенная граница реализации.

## Подключение своих скриптов

В **Скрипты и мосты** выберите `.py`, задайте название/ключ и нажмите
«Добавить и запустить». Крест проверит синтаксис без импорта скрипта, сохранит
регистрацию в локальном `config.json`, запустит процесс и подключит журнал.
Для встроенного сервиса можно выбрать заменяющий файл кнопкой «Найти скрипт бота».
Применение замены требует сохранения и перезапуска сервиса. Пакеты, нужные стороннему
скрипту, следует установить в окружение Крест. Они не угадываются и не ставятся
автоматически. Скрипт выполняется с правами пользователя; выбирайте доверенный код.

Крест передаёт:

- `KREST_SERVICE_TOKEN` — ключ данного пользовательского сервиса;
- `KREST_SERVICE_ID` — его идентификатор;
- `KREST_CONFIG_PATH` — путь общего конфига;
- `KREST_DATA_DIR` — папку состояния/уведомлений;
- `PYTHONPATH` — доступ к `bridge_sdk` и модулям Крест.

Простой скрипт сразу получает управление процессом и журнал. Для уведомлений и
команд скрипт должен явно поддерживать протокол. Крест не может автоматически
угадать интерфейс произвольной программы. Пример: `examples/bridge_example.py`.

```python
from bridge_sdk import emit, commands

emit("ready", "Мост готов", capabilities=["refresh"])
for request in commands():
    if request["command"] == "refresh":
        emit("status", "Проверка завершена")
        emit("notification", "Получено важное событие")
```

События пишутся в stdout как `KREST_EVENT {JSON}`; команды приходят строками JSON
в stdin. Поддержаны события `ready`, `status`, `notification`, `error` и команда
`refresh`, если скрипт объявил её в `capabilities`. Остальной stdout/stderr попадает
в журнал. Скрипт может читать свой токен из окружения, но не должен печатать его.
После выбора скрипта Крест не исправляет его исходники и не подменяет его API.

Флажок автозапуска действует при следующем запуске Крест; автозапуск самой Крест
с Windows включается отдельно в настройках. Проверка ядра показывает загрузку
навыков, свободное место и доступность очереди. Кнопка проверки уведомлений
проходит через настоящую локальную очередь. При завершении Крест её дочерние
сервисы останавливаются. «Отключить и убрать» удаляет регистрацию, сохраняя файл.

## Проверка новой интеграции

Запустите `python -m pip install -r requirements-dev.txt`, затем `python main.py --check`
и `python -m pytest -q`. Облачные тесты проверяют пагинацию и неполные ответы Steam,
приватность/ошибки/ограничение частоты, подтверждённое снятие запрета, сохранность
кэша при сбое, локальные библиотеки, реальные дочерние процессы, двусторонний мост,
доставку через очередь и новые страницы GUI. Вызовы Telegram подменены: тесты никому
не отправляют сообщения.

В этой среде Steam/Discord-сайты недоступны через сетевой прокси. Реальные ответы
вашего Steam-аккаунта, доставка в Telegram и Rich Presence с настольным Discord
не проверены. До этих проверок интеграцию следует считать готовой к локальному
тестированию, а не подтверждённо работающей с вашим аккаунтом.

Документация платформ: [Steam IPlayerService](https://partner.steamgames.com/doc/webapi/IPlayerService),
[Steam ISteamUser](https://partner.steamgames.com/doc/webapi/ISteamUser),
[Discord self-bots](https://support.discord.com/hc/en-us/articles/115002192352-Automated-User-Accounts-Self-Bots).

## Сценарии и уточнения команд

На странице **Сценарии** уже есть «Игра», «Работа», «Отдых»: они переключают профиль
нагрузки и озвучку уведомлений. Добавьте свои программы и команды, например
`громкость на 30`. Выбор программы сохраняет полный путь; файл запускается отдельным
процессом без командной оболочки. Программа должна существовать на вашем компьютере.
Список шагов служит предпросмотром: можно заменить шаг, удалить его и изменить порядок.
Нажмите **Сохранить сценарий**, затем **Запустить сохранённый**. Для запуска голосом:
`крест запусти сценарий Игра`.

При ошибке дальнейшие шаги прекращаются. **Остановить** или `останови сценарий`
отменяет оставшиеся шаги, но не закрывает уже открытые программы и не откатывает
выполненные действия. Пока длинная команда выполняется, кнопка остановки сценария
доступна в меню. Вложенные сценарии запрещены. Режимы, выбранные сценарием, действуют
до следующего переключения или перезапуска; кнопки применения на страницах нагрузки
и уведомлений возвращают управление сохранённым настройкам.

После создания таймера можно сказать `добавь ещё пять минут` или `отмени его`.
После срабатывания напоминания — `отложи на пятнадцать минут` или `выполнено`.
Последняя выбранная задача запоминается на 120 секунд. Если подходящих задач несколько,
Крест перечисляет их и ждёт название или номер; уточнение также действует 120 секунд.
Другая команда снимает ожидающее уточнение. Голосовой ввод по-прежнему требует
обращения «крест» вне настроенного окна активного слушания. Генеративная модель не нужна.

## Расписание и история дел

В **Таймеры** выберите дни недели и время. Голосовые варианты:
`напоминай по будням в 09:00 зарядка`, `напоминай по выходным в 11:00 уборка`,
`напоминай по понедельникам в 18:00 тренировка`. Старые ежедневные задачи продолжают
срабатывать каждый день. Пустое расписание не сохраняется.

**Готово** записывает выполнение, **Отложить** создаёт новое срабатывание и сохраняет
связь с повторяющейся задачей. Расписание остаётся действующим. На странице показаны
последние 30 завершённых напоминаний, на диске хранятся последние 500.
`план на сегодня` и утреннее приветствие учитывают дела на текущую дату, непрочитанные
напоминания и количество завершённых дел за день. Крест не создаёт повторяющиеся
задачи по догадке: расписание задаёт пользователь.

## Уведомления, нагрузка и диагностика

**Уведомления** хранит события задач, ботов, сценариев, сортировки и музыкальных команд
в `inbox.sqlite3`. Одинаковые непрочитанные события одного источника и приоритета
за минуту группируются со счётчиком; повтор не озвучивается. Хранятся последние
1000 групп, в списке показаны последние 300. «Прочитано» относится к уведомлению,
а выполнение задачи отмечается отдельно. Эта история отличается от краткоживущей
очереди доставки между процессами.

Режимы озвучки: все, только важные, без озвучки. По умолчанию во время игры
озвучиваются только важные события: срабатывания напоминаний и сообщения Steam
о доступности обмена. Обычные события остаются в центре; настройки озвучки не скрывают
всплывающие сообщения трея. Свой мост может передать приоритет:
`emit("notification", "Событие", priority="high")`; допустимы `low`, `normal`, `high`.

На странице **Нагрузка и файлы** доступны автоматический, обычный, игровой и экономный
профили. Автоматический проверяет имена процессов раз в 10 секунд; по умолчанию
указаны `cs2.exe,dota2.exe`, список можно изменить. В игре и экономном режиме
новые проходы автосортировки откладываются, замеры выполняются раз в 10 секунд вместо
5, период опроса Steam и Discord Presence увеличивается втрое. Уже начатое файловое
действие завершается. Ручные команды и сроки напоминаний сохраняются.

CPU/RAM включают процесс Крест и дочерние процессы. CPU нормирован на число
логических процессоров, RAM — сумма RSS, которая может повторно учитывать общие
страницы памяти. Первый замер CPU может быть нулевым. Замеры не являются обещанием
нагрузки на конкретном компьютере. Vosk/Silero и их модели не заменяются,
проверки GPU и новые тяжёлые модели не добавлены.

В **Музыка → Диагностика плеера** отображаются источник, текущий трек, разрешённые
плеером команды и доступные кнопки отметки. Диагностика не нажимает кнопки. Если
лайк не обнаружен, показаны доступные подписи кнопок или причина ошибки адаптера.
Универсальное управление любой программой не гарантируется: возможности зависят
от её медиасессии и доступности элементов интерфейса. Windows и настольную Яндекс
Музыку нужно проверить на вашем компьютере.
