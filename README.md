# KREST OS · Реликт — голосовой помощник для Windows

Голосовые команды, управление музыкой и компьютером, напоминания, Steam,
Telegram/Discord, помощник Warframe. Боты и дополнительные темы
доступны после активации Premium в меню.

## Обновление 0.19.0 · Покажи один раз

**Команды → Покажи один раз** позволяет обучить Крест последовательности кнопок
в вашей программе и запускать её голосом. Расширение доступно в обычной версии.
Сохраняются названия, идентификаторы и расположение элементов в дереве доступности
Windows. Перемещение окна не меняет эти идентификаторы; новая модель не требуется.

1. Скажите **«Крест, учись действию подготовка дискорда»** или введите название на
   странице обучения. Откройте нужную программу в исходном состоянии.
2. Наведите мышь на кнопку и скажите **«Крест, запомни кнопку»** либо нажмите
   **Ctrl+Alt+F9**. Крест прочитает элемент. Нажмите кнопку вручную, перейдите к
   следующему шагу и повторите. Это управляемое обучение отдельных шагов.
3. Скажите **«Крест, сохрани действие»**. Перед сохранением можно убрать последний
   шаг или отменить весь черновик. Черновик действует 15 минут после последнего шага.
4. Для повторения: **«Крест, выполни действие подготовка дискорда»**. Программа
   должна быть запущена и находиться в исходном разделе. Крест выведет её окно
   вперёд и выполнит сохранённые шаги. **«Проверь действие подготовка дискорда»**
   проверяет доступность первого элемента без нажатий и переключения окна.
5. **«Крест, останови действие»** останавливает оставшиеся шаги.
   **«Мои обученные действия»** перечисляет сохранённые названия.

Поддерживаются доступные через Windows UI Automation кнопки, вкладки, переключатели
и раскрывающиеся элементы. Один навык относится к одной программе, содержит до
12 шагов; всего можно сохранить 30 действий. Смена активной программы, неоднозначная
цель или изменение интерфейса останавливают выполнение. Переходы между диалогами
должны быть показаны при обучении. Ввод текста и управление 3D-игрой в этот механизм
не входят. Для Electron-приложений Крест запрашивает дерево доступности, однако
наличие необходимых элементов зависит от самого приложения.

Нажатие отправляется один раз. Повторяется только поиск ещё не появившегося элемента
(до восьми секунд), а тайм-аут отправки останавливает цепочку. Переключатели проверяются
по состоянию: повторное «включить» не должно выключать уже включённый элемент.
Для обычной кнопки фиксируется факт отправки; её внутренний результат приложение
может не предоставлять. Шаги и причина остановки видны в меню. Сохранённые действия
входят в резервную копию, после переноса выключены до проверки пользователем.
Автоматического запуска после перезапуска Крест нет.

**Оптимизация ядра и меню:**

- В трее полное состояние запрашивается раз в восемь секунд; новое событие будит
  клиент сразу. На обычной странице интервал — секунда, на главной и голосовой —
  полсекунды. Прослушивание и отдельный голосовой индикатор работают независимо.
- Цикл передачи событий ядра ждёт очередь; в простое его периодические пробуждения
  сокращены с десяти до двух в секунду. При поступлении события ожидание заканчивается.
- Обучение не опрашивает экран в фоне. Доступ к кнопкам вынесен в отдельный
  ограниченный по времени помощник Windows с пониженным приоритетом. Музыка и
  микрофон Discord используют отдельные очереди и помощники.
- Страница обучения обновляет строки только когда открыта; сохранение и удаление
  действий применяются сразу, отдельное сохранение общих настроек не требуется.

В локальном сравнении за 12 секунд скрытое меню получило **1 полный снимок вместо
24**, объём ответов составил около **5,5 КБ вместо 129 КБ**. Это измерение обмена
ядра и клиента без голосовых моделей, а не прогноз FPS или нагрузки Vosk в игре.
Папка программы и ZIP по-прежнему собираются через `build-exe.bat`.

## Обновление 0.18.0 · Мозг действий

**Система → Мозг** показывает поручения, шаги команды и их результат. Диспетчер
работает на существующих навыках и правилах, без новой нейросети и нагрузки на GPU.

- **Приоритет голоса.** Команды пользователя опережают ожидающие фоновые поручения
  в своей очереди. Длительное ожидание постепенно повышает приоритет остальных задач.
  Уже отправленное приложению действие не прерывается. Отмена освобождает место в очереди.
- **Проверка результата.** Для поддерживаемых действий плеера и запуска программ
  Крест сопоставляет подтверждение с конкретным шагом. Если подтверждения нет,
  следующие шаги цепочки останавливаются. Для остальных навыков отдельно указано,
  что успех сообщил сам навык. Одиночная команда отправляется сразу, проверка идёт
  отдельно; повторного нажатия из-за задержки подтверждения нет.
- **Защита от запоздавших команд.** Если голосовое управление треком, громкостью,
  микрофоном или скриншотом провело в очереди больше десяти секунд, Крест предложит
  повторить запрос. Таймеры и напоминания по этому правилу не отбрасываются.
- **Поручения с условием.** Во время игры: «Крест, после игры таймер на две минуты».
  После игры также доступны запуск известных программ и игр, напоминания и погода.
  «Крест, когда компьютер свободен проверь подключения при простое» ставит проверку
  в существующее дежурство. При AFK разрешены только резервная копия настроек,
  проверка подключений и проверка копий; действуют выбранный порог простоя
  (по умолчанию 20 минут), запрет работы во время игры, просмотра и другой активности.
  Условие и актуальность команды проверяются ещё раз перед выполнением.
- **Управление голосом.** «Что ты сейчас делаешь», «объясни последнее действие»,
  «покажи план переключи трек и таймер на две минуты», «отмени последнее поручение»,
  «останови команды». Предпросмотр плана ничего не выполняет. Остановка убирает
  ожидающие команды и оставшиеся шаги; уже выполненные действия сохраняются.
- **Восстановление.** Сохранённые поручения доступны после перезапуска. Для условия
  «после игры» нужна новая обнаруженная игровая сессия. Если Крест закрылась во время
  отправки действия, оно отмечается прерванным и автоматически не повторяется.
- **Оптимизация.** Убрана повторная обработка всей голосовой фразы при выборе блокировки
  действия. Проверка запуска программы читает путь только у процессов с подходящим
  именем. Поток проверки результата завершается после простоя. Мозг использует уже
  работающий планировщик, не пишет журнал без изменений; страница обновляется только
  когда открыта. Хранятся до 200 завершённых записей каждого вида и активные поручения.

Сборка по-прежнему создаёт папку программы и ZIP. Для обновления исходников используйте
`update.bat`, затем пересоберите программу через `build-exe.bat` и полностью
перезапустите Крест. Новая вкладка требует обновления и меню, и фонового ядра.

## Обновление 0.17.1 · Нагрузка в игре и музыка

- Распознавание больше не занимает повышенный приоритет MMCSS Audio: этот класс
  предназначен для передачи звука. Прослушивание и быстрые команды продолжают работать.
- Vosk получает только текст промежуточных результатов. Лишнее выравнивание слов
  каждые 90 мс отключено; уверенность и слова итогового результата сохраняются.
- При обнаружении Dota или другой игры Silero использует один поток CPU, а поток
  синтеза работает с пониженным приоритетом Windows. После игры возвращается заданный
  бюджет потоков. Модели и устройства не перезапускаются при смене режима.
- Сканирование установленных приложений откладывается до выхода из игры; уже
  известные голосовые названия остаются доступны.
- Новая посторонняя аудиосессия больше не вызывает восстановление и повторное
  приглушение музыки. Профиль меняет только нужные сессии; неизменённая громкость
  повторно не отправляется, журнал восстановления не переписывается при каждом опросе.

## Обновление 0.17.0 · Автоматизация выбранных задач

Новые вкладки — **Автоматизация → Обработка загрузок / Наблюдение / Привычки**
и **Музыка → Звуковой диспетчер**. Автоответчик в этом обновлении не изменяется.

- **Команды для выбранного объекта.** Выделите файлы или папки в активном
  Проводнике: «Крест, упакуй это», «открой это», «покажи это в папке».
  ZIP создаётся в `archives` рядом с данными Крест, проверяется по CRC;
  исходники сохраняются. Лимит одной упаковки — 10 000 файлов / 20 ГБ,
  операцию можно остановить в журнале заданий. В меню есть выбор файлов и папки.
  «Открой последний скриншот» работает напрямую с папкой `screenshots`.
  Выбранный контекст действует пять минут; виртуальные папки и ссылки не используются.
- **Обработка загрузок по правилам.** Выберите папку источника, отдельную папку
  результата и маску (`*.zip`, `*mod*.zip`, `*.exe`; несколько масок через `;`).
  После двух минут стабильности файла Крест проверяет SHA-256, сохраняет копию,
  ищет точные дубликаты среди первых 500 файлов папки результата и, если включено,
  распаковывает ZIP в отдельную папку. Оригиналы и дубликаты не удаляются,
  установщики не запускаются. Файлы правила исключаются из обычной сортировки.
  Голосом: откройте папку назначения и скажите «Крест, архивы с модами складывай
  сюда и распаковывай» — правило ищет `мод` и `mod` в именах ZIP из загрузок.
  Результаты, ошибки и ручной повтор доступны на той же странице.
- **Наблюдение за операциями.** До 20 выбранных наблюдений: установка Steam,
  задача дежурства, файл, папка или конкретный PID с проверкой времени его запуска.
  «Сообщи когда скачается варф» использует локальный манифест Steam;
  пауза и незавершённая установка не считаются успехом. «Следи за загрузками сюда»
  наблюдает только за открытой папкой, сообщая о новых закрытых стабильных файлах.
  Для обычного файла стабильность не выдаётся за доказательство завершения загрузчика,
  а закрытие чужого процесса — за успешное выполнение его задачи.
  Сетевые загрузки, порученные самому дежурству, сохраняют его возобновление и
  ограниченные повторы; произвольные внешние программы автоматически не перезапускаются.
- **Результат и выключение после задачи.** Можно включить отправку результата
  владельцу настроенного Telegram-пульта (Premium). Неопределённая доставка
  отмечается в меню и автоматически не повторяется. «После завершения копирования
  выключи компьютер» выбирает единственную активную задачу копирования Крест;
  при нескольких задачах нужна конкретная строка в меню. Выключение доступно
  после подтверждённого результата Steam / дежурства, ждёт AFK, отсутствия текущей
  установки и даёт 60 секунд на «отмени выключение». Перезапуск Крест снимает
  ещё не отправленное отложенное выключение. Обычные наблюдения сохраняются.
- **Звуковой диспетчер.** Сначала сохраните обычный звук, затем желаемые профили
  игры, звонка и наушников. «Запомни звук для игры» сохраняет устройства Windows
  и громкость однозначных аудиосессий. Переключатель включает применение при смене
  режима и подключении новых сессий; ручные изменения внутри режима не перетираются.
  Звонок определяется по активному захвату микрофона Discord, Zoom, Teams, Skype
  или Telegram, а не наличию их процесса. Музыка приглушается и восстанавливается
  после завершения захвата. Браузерные звонки этим способом не определяются.
  «Приглуши всё кроме Дискорда» временно снижает остальные сессии до 20% исходной
  громкости; «верни обычный звук» возвращает её с учётом ручных изменений.
  Устройства, жёстко выбранные внутри сторонней программы, Windows может не переключить.
- **Предложения по привычкам.** Запоминаются только успешные команды Крест:
  запуск приложений, точная громкость и звуковые режимы. Ищутся одинаковые цепочки
  из 2–5 команд в течение трёх минут после запуска Крест, игры или подключения
  наушников. Три повторения в сессиях с интервалом хотя бы десять минут создают
  предложение. Перед включением видны все шаги и точный триггер; правило можно
  отключить здесь или в «Событиях». Экран, клавиши и ручные действия вне Крест
  не записываются. Отправка сообщений, удаление и выключение в предложения не входят.

Тяжёлая обработка загрузок использует существующий AFK-работник: стандартные
**20 минут** простоя, остановка при возвращении, игре, просмотре или звонке.
Явные команды пользователя выполняются сразу. Один лёгкий координатор проверяет
выбранные наблюдения раз в 5 секунд (папки — раз в 20 секунд). Выключенный звуковой
диспетчер не опрашивает устройства; включённый использует изолированный помощник
с ограничением времени. Сетевые уведомления не задерживают звук и отмену задач.
Таблицы меню обновляют изменённые строки, сохраняя выделение; скрытые страницы
не запускают обновление. Vosk и Silero остаются прежними.

Правила и звуковые профили включены в резервную копию; при переносе автоматическое
выполнение отключено. Активные наблюдения и временный прогресс файлов в переносимую
копию не входят. Сборка остаётся прежней: **`build-exe.bat` → `dist/Krest` + ZIP**.

## Обновление 0.16.0 · Контекст, восстановление и дежурство

- **ShareX больше не считается игрой.** Его установка через Steam, работа в трее
  и дочерний кодировщик не удерживают дежурство в игровом режиме. Пауза на время
  настоящих игр и ожидание 20 минут простоя сохранены.
- **Короткий голосовой диалог.** После успешного действия Крест на 10 секунд
  сохраняет его цель. «Крест, открой Яндекс Музыку» → «сделай потише» →
  «ещё немного». Продолжение меняет громкость найденной аудиосессии приложения;
  системная громкость остаётся отдельной командой. После управления треком
  сохраняется конкретный плеер, после мута Discord можно сказать «включи обратно».
  «Хватит», новая команда с обращением, смена профиля, выключение голоса или
  истечение времени закрывают контекст. Отрицания, посторонние фразы и команды
  других разделов не выполняются. Переключатель — на странице голоса.
- **Открытие музыки.** Яндекс Музыка и Spotify сначала ищутся в каталоге установленных
  программ; при отсутствии открывается сайт. Контекст громкости приложения требует
  доступной однозначной аудиосессии Windows. Для сайта в браузере такая связь по
  открытой ссылке не предполагается.
- **Проверка подключений — Система → Ядро.** Микрофон считается работающим по свежим
  аудиоблокам. Боты — по своим сообщениям о соединении, а не только по PID.
  Скрипт без таких сообщений получает состояние «не подтверждено».
  Есть ручная проверка, восстановление, последние причины и журнал изменений.
  Голосом: «проверь подключения», «почини подключения», «отчёт о подключениях».
- **Ограниченное восстановление.** Зависший или длительно отключённый управляемый
  бот использует общий лимит 3 перезапуска за 10 минут. Ошибка входа требует
  авторизации. Остановленный пользователем микрофон сам не включается. Для плеера
  проверяется доступность и освобождается неисправный помощник, если он не занят;
  переключение трека и лайк повторно не отправляются. Получение состояния плеера
  не объявляется подтверждением выполнения его последней команды.
- **Пробное восстановление копий.** Каждая новая копия настроек распаковывается во
  временную папку: проверяются хеши, JSON и целостность SQLite. Раз в сутки AFK может
  проверять до 5 сохранённых версий файлов; набор меняется по дням. На вкладке версий
  доступна отдельная кнопка проверки выбранного файла. Рабочие файлы не заменяются.
- **Подготовка обновлений.** В Дежурстве выберите «Скачать установщик без установки»,
  найдите программу в списке winget и добавьте поручение или правило. Winget скачает
  актуальный пакет; путь и SHA-256 сохранятся в результате. Это подготовка текущего
  установщика, а не утверждение, что установленная версия устарела. При возвращении
  загрузка прерывается; следующая попытка начинает её заново. Обновление программы
  остаётся отдельным поручением winget и может скачать пакет повторно. Начатая
  установка завершается после возвращения, следующие задачи ждут AFK.
- **Общая очередь обслуживания.** Сортировка загрузок переехала из отдельного
  фонового потока в дежурство: проверка каждые три минуты AFK, сохранены ожидание
  стабильности файла, исключения и отмена сортировки. Кнопка «Подготовить обслуживание
  при AFK» и команда «подготовь обслуживание» ставят копию настроек, проверку версий,
  подключения и включённую сортировку в очередь без дублирования ожидающих задач.

Стандартное дежурство начинается через **20 минут** простоя. Игра, видео, звонок,
возвращение к ПК и нехватка ресурсов блокируют обслуживание. Модели Vosk/Silero
остались прежними. Контекст — небольшое состояние в памяти; проверка голоса читает
телеметрию раз в 30 секунд. Новых постоянно опрашивающих устройств потоков нет.
Обновление исходников и сборка: **`build-exe.bat`**. Выход: папка `dist/Krest` и ZIP.

## Обновление 0.15.5 · Надёжная сборка и лёгкий захват звука

- `build-exe.bat` восстанавливает повреждённое или несовместимое окружение
  сборки, сохраняя старую папку. Повторный запуск переиспользует проверенные
  зависимости; изменение требований или состава пакетов запускает подготовку снова.
- Все этапы, включая установку библиотек, сохраняются в `build/build-last.log`.
  Предыдущий журнал — `build/build-previous.log`. Два сборщика одновременно
  не могут менять одну сборку. Запущенная из `dist` Крест обнаруживается заранее.
- Модели подготавливаются до упаковки, библиотеки проверяются до и после неё.
  Папка программы заменяется после создания и проверки ZIP; при ошибке замены
  выполняется откат. Прежняя папка сохраняется в `dist/Krest-previous-*`.
- Windows CI теперь запускает тот же `build-exe.bat`, что и пользователь,
  и проверяет повторный запуск подготовленного сборщика.
- Уровень обычного 30-миллисекундного блока микрофона вычисляется один раз вместо
  двух. Нестандартные размеры блоков, отметки пропусков и защита от запоздалых
  команд сохранены. Это уменьшает обработку захвата без смены Vosk/Silero.
- Проверка игр сначала смотрит имена процессов. Для известной игры и при пустой
  библиотеке не читает пути всех процессов; при проверке Steam использует поиск
  по родительским папкам вместо сравнения с каждой установленной игрой.

Для обновления полностью завершите Крест через трей, обновите исходники и
запустите **`build-exe.bat`**. Результат — папка **`dist/Krest`** и ZIP в `dist`.
Если сборка остановилась, полный текст ошибки остаётся в **`build/build-last.log`**.
Точная причина прежнего сбоя на конкретном ПК определяется по его журналу.

## Обновление 0.15.0 · Дежурство

Новый раздел **«Дежурство»** выполняет выбранные поручения, пока ПК свободен.
По умолчанию — после двадцати минут без ввода. Игра, воспроизведение, звонок,
полноэкранное приложение, высокая нагрузка CPU или недостаток памяти откладывают
работу. Учитываются клавиатура, мышь, XInput-геймпад и обращение к Крест.
Если Windows не позволяет проверить активность, очередь остаётся на паузе;
причина показана сверху страницы. Это консервативная проверка, а не наблюдение за экраном.

- **Постоянная очередь:** копирование, загрузка по HTTP(S), создание и распаковка ZIP,
  версии файлов, перенос старых файлов на другой диск, обновление выбранных программ
  через winget. Папки и программы задаются в меню; целые диски и системные каталоги
  автоматически не перемещаются. Есть отмена, повтор и приоритет.
- **Возвращение к ПК:** файловые задачи останавливаются между блоками данных;
  копирование и поддерживаемые сервером загрузки продолжаются после следующего AFK.
  ZIP при прерывании собирается заново. Начатая установка программы завершается;
  новая установка при активности не запускается. После сбоя ядра установщик
  автоматически повторно не запускается, неизвестный результат требует проверки версии.
- **Версии и место:** копии проверяются SHA-256, исходник при переносе удаляется
  только после проверки. Хранятся пять последних версий каждого файла; изменённые
  вручную копии не удаляются. Восстановление сохраняет текущий файл и создаёт отдельную
  копию, а перенос позволяет вернуть файл в свободный исходный путь.
- **Правила и привычки:** почасовые, ежедневные и еженедельные поручения. Пять
  успешных ручных задач с одинаковыми параметрами минимум в три разных дня могут
  создать ежедневное правило. Обучаются только копирование, версии и ZIP;
  отмена задачи или отключение изученного правила запрещает дальнейшее обучение
  этому повтору. Имена правил доступны голосом. Это обучение повторам заданных
  поручений, не произвольным действиям в приложениях.
- **Telegram-пульт:** файлы владельца сначала ставятся в очередь и загружаются в
  `uploads` при AFK; ZIP можно автоматически распаковывать в `received`.
  В пульте добавлен раздел дежурства. Приём файлов и команды включаются в настройках
  доступа; существующий пользовательский список разрешений не расширяется молча.
- **Обслуживание Крест:** ежедневная копия настроек без секретов (последние семь),
  проверка управляемых подключений каждые 30 минут простоя. Автосортировка загрузок
  и фоновая индексация файлов также ждут AFK. Голос, ручные команды и обычная работа
  ботов продолжаются во время использования ПК.

Голосом: **«статус дежурства»**, **«останови дежурство»**, **«продолжи дежурство»**,
**«сохрани настройки в очередь»**, **«проверь подключения при простое»**,
**«запусти правило архив документов»**. Приостановка сохраняется между запусками.

Очередь и правила лежат в `autonomy.sqlite3`, служебные копии и журналы — в
`autonomy`. Они не входят в распространяемую сборку или переносимую резервную копию
профиля. За проход — до 10 000 файлов / 20 ГБ; незавершённые загрузки и файлы,
менявшиеся за последние две минуты, пропускаются. Telegram Bot API ограничен
20 МБ на входящий файл. Файловые задачи оставляют резерв 2 ГБ на диске назначения.
Windows-зависимые проверки выполняются отдельным потоком;
один исполнитель очереди использует пониженный приоритет и не загружает GPU.
Формат выпуска сохранён: папка программы и ZIP.

  обычное управление. Во время теста остальные голосовые действия тоже приостановлены.
- **Автозапуск:** до 45 секунд на холодный запуск ядра, короткие проверки готовности,
  повторное подключение при устаревшем адресе и блокировка одновременных запусков.
  Ранний вывод процесса сохраняется в `logs/startup.log` папки данных.

Скорость и точность на живом голосе зависят от микрофона, фона и нагрузки игры.

  пропускаются. Фильтр похожих на ключи строк не гарантирует обнаружение всех секретов.
- **Слух:** отдельное обращение «Крест» открывает окно слушания сразу, даже при занятой
  очереди. Команда, принятая в этом окне, сохраняет обращение при ожидании выполнения.

## Обновления и меню

`start.bat` проверяет зависимости уже скачанной версии; `build-exe.bat` собирает

ZIP без истории Git обновляйте новой распаковкой, сохраняя `model` и личные данные.
Готовый EXE обновляется новой ZIP-сборкой, а не батником для исходников.

Декоративные снег, кровь и частицы удалены вместе с настройками и фоновыми
таймерами. Старые параметры эффектов больше не используются. Игровой крест и

### Формат пакета навыков

Кнопка «Шаблон пакета» в каталоге команд создаёт минимальный рабочий ZIP.
В корне находятся `krest-extension.json` и `entry.py`. Функция получает словарь
`context` с `settings`, `text` (команда), `event` (событие) или `undo` (отмена).
Возврат: `{"text": "Результат"}`; опционально `notifications` — список строк
при разрешении `notifications`, `undo` — JSON-данные для функции отмены,
указанной в записи команды как `"undo": "имя_функции"`.

Доступные события: `assistant.started`, `game.started`, `game.stopped`,
`timer.due`; подпишите функцию через объект `events` в манифесте.
Обработчики не должны требовать непрерывного потока событий: пока предыдущая
группа событий выполняется, новые пропускаются. Настройки поддерживают
`boolean`, `integer` (с `min`/`max`) и `string`, обязательное значение `default`.
Код новых пакетов запускается только после импорта с предпросмотром.
Автоматическая запись пользовательских действий в сценарии не добавлена.

  сама кнопка, затем при необходимости панель текущего трека; проверка результата
  сохранена. Discord учитывает новые подписи, дочернее окно Electron и разделённую
  панель пользователя. Окно из трея временно показывается позади активного окна и
  возвращается в прежнее состояние.
- **Голос → «Играю в наушниках»** сразу сохраняет режим, позволяющий говорить во
  время ответа Крест. Существующая настройка для колонок сама не меняется.
  Диагностика отдельно показывает захват звука, буфер, Vosk, паузу, очередь и действие.
- Windows-сборка проверяет поток распознавания синтезированными фразами Silero
  через настоящий Vosk, включая тихий сигнал и небольшой шум. Это проверка
  комплектных моделей, а не измерение точности на вашем микрофоне.

Команды: **«Крест, мут»**, **«Крест, включи микро»**, **«Крест, я в муте»**,
**«Крест, переключи трек»**, **«Крест, поставь лайк»**. Если Discord не предоставляет
кнопки через Windows или запущен с другими правами, Крест сообщает об этом и не
переключает микрофон вслепую. Реальное поведение клиента проверяется на вашем ПК.

## Характер и разговор

Семь личностей имеют по 69 собственных реплик для 23 ситуаций и общий набор из
20 фактов. Ответы в одной теме чередуются без повторения до конца набора.
Стиль выбирается в профиле; голосовая модель остаётся прежней, интернет не нужен.
Это локальная база диалогов, а не свободно обучающаяся разговорная модель.

Попробуйте: «Крест, я вернулся», «у меня получилось», «меня всё бесит»,
«помоги сосредоточиться», «мне нужен перерыв», «вдохнови меня», «ты классная»,
«пожелай удачи в игре», «ты меня слышишь», «спокойной ночи», «до встречи».
Разговор о перерыве или сне сам по себе не запускает таймер и не выключает ПК.

## Яндекс Музыка и другие плееры

Текущий источник выбирается по медиасессиям Windows. Пауза, продолжение,
предыдущий/следующий трек работают через медиасессию. Лайк в настольной Яндекс
Музыке и Spotify ищется через доступные элементы окна: сначала панель текущего
трека, затем её кнопка отметки. Поддержаны дополнительные названия кнопок
коллекции и идентификаторы настольного приложения. После нажатия проверяются
состояние отметки и неизменность трека; повторный лайк не должен снимать отметку.

Доступ к кнопкам выполняется в отдельном короткоживущем процессе с лимитом
ожидания 20 секунд. Зависший помощник доступа завершается отдельно от ядра.

Для лайка Крест также ищет скрытое окно плеера в трее и временно открывает его
позади других окон, не переводя фокус с игры; затем возвращает прежнее состояние.
Крест запрашивает у Electron дерево доступности без перезапуска приложения. Если приложение не
отдаёт подписи или состояние кнопок, действие завершается с объяснением:
координаты и глобальные горячие клавиши наугад не используются. «Музыка →
Проверить доступные команды и лайки → Диагностика плеера» показывает найденный
источник и кнопки, ничего не нажимая. Совместимость конкретной версии плеера
проверяется на Windows с запущенной музыкой.

## Голос: просто положите папку model рядом с программой

Поддерживаются оба варианта:

```text
Крест/
  main.py                  # или Krest.exe в готовой сборке
  model/
    am/final.mdl
    conf/model.conf
    model_silero.pt         # если есть файл голоса Silero
```

или распакованная модель внутри `model/vosk-model-small-ru-.../`. Крест ищет
модели до трёх уровней вложенности в `model`, `models`, `voice`; в EXE-версии
проверяет папку рядом с EXE независимо от рабочей папки запуска. Файлы Silero
`model_silero.pt`, `silero.pt`, `v4_ru.pt`, `v3_1_ru.pt`, `v3_ru.pt` тоже находятся
внутри `model` автоматически. Сохранённый существующий путь имеет приоритет.

Vosk распознаёт речь, Silero озвучивает ответы. Если имеется только Vosk,
распознавание может работать без озвучки. Недостающие модели при разрешённой
автозагрузке скачиваются с официальных серверов; найденная лёгкая модель не
заменяется большой. При нескольких неоднозначных моделях выберите нужную в меню.
Оборванные или повреждённые файлы Silero не считаются готовой моделью. Озвучка
восстанавливается в фоне с повторными попытками; микрофон продолжает слушать.
В разделе «Голос» видны ход загрузки и конкретная причина ошибки.

При `Failed to create a model` проверяется комплектность Vosk. Повреждённую
модель Крест пытается восстановить в отдельной папке, сохраняя ваши файлы.
Для путей с кириллицей используется короткий путь Windows, если он доступен.
При отсутствии интернета восстановление повторяется с паузой. Обычная Windows-
сборка проверяет загрузку Vosk также из папки с русским именем.

Для полностью распознанных коротких команд используется пауза от 400 мс:
словарь включает музыкальные команды, mute и ваши соответствующие синонимы.
Незавершённая гипотеза Vosk не выполняется. В разделе «Голос» есть режим
**«Я в наушниках: слышать команды во время ответа»**; включайте его при прослушивании
Крест через наушники, чтобы исключить захват её ответа через колонки.
Прослушивание работает в ядре независимо от меню. В трее есть «Возобновить
прослушивание»; устаревшая запись после длительного зависания отбрасывается.

Микрофон выбирается автоматически: сначала системный вход Windows, затем другие
доступные устройства. Крест подбирает частоту USB/Bluetooth-микрофона и переводит
звук в нужный для распознавания формат. Если вход перестал передавать данные,
Крест пробует следующий. При тишине из-за mute она показывает подсказку.
Кнопка **«Автоматически подключить микрофон»** сбрасывает старый выбор устройства,
включает адаптацию чувствительности и перезапускает подключение. Если Windows
запретила микрофон, кнопка рядом открывает параметры доступа для классических приложений.

## Собрать программу в EXE

**Дважды нажмите build-exe.bat.** На компьютере автора нужен Python 3.11/3.12 x64;
если его нет, сначала откройте `start.bat`. Скрипт создаёт отдельную среду сборки,
устанавливает CPU-зависимости и упаковывает приложение через PyInstaller.
Visual Studio, Nuitka и Inno Setup не требуются.

Результат: **dist/Krest/Krest.exe** и **dist/Krest-Windows-0.16.0.zip**.
Передавайте пользователю ZIP целиком. Каталог `_internal` содержит необходимые
библиотеки: его нельзя удалять или отделять от EXE. **Модели Vosk и Silero входят
в обычную сборку автоматически**, в папку `model` рядом с EXE. Отсутствующие модели
скачиваются при сборке; если подготовка или синтез не удались, новый ZIP не создаётся.
Пользователю Python и загрузка моделей для этой сборки не нужны. Архив нужно сначала
полностью распаковать, затем запускать `Krest.exe` из распакованной папки.
Предыдущая сборка при повторном запуске сохраняется в `dist/Krest-previous-*`.

Дополнительные параметры для автора:

```bat
build-exe.bat --protect
build-exe.bat --protect --license "C:\путь\лицензия-pyarmor.zip"
build-exe.bat --without-models
```

Старый параметр `--with-models` поддерживается, но больше не требуется.
`--without-models` создаёт специальный облегчённый ZIP с пометкой `online-setup`:
ему нужен интернет при первом запуске. Для передачи друзьям используйте обычную сборку.

Обычный режим прячет Python-модули внутри пакета, но **байткод можно извлечь**.
`--protect` применяет PyArmor: собственный код обфусцируется и выполняется через
защитный runtime. Это затрудняет анализ, но не гарантирует полной секретности.
Для размера этого проекта может понадобиться лицензия PyArmor; при ограничении
лицензии или ошибке защиты сборка прекращается без незащищённой подмены.
PyTorch и прочие сторонние библиотеки упаковываются в готовом виде.

В сборку не копируются тесты, отчёты, Git, основные исходники проекта в виде открытых `.py`,
пользовательские настройки, сессии ботов и приватные ключи. После упаковки автоматически
проверяются загрузка команд, отдельный процесс ядра, импорт голосовых/сервисных
библиотек и настоящий синтез Silero с загрузкой Vosk. Проверка моделей запускается
из чистого профиля без их скачивания. Она не отправляет сообщения и не обращается
к микрофону или динамикам; проверка конкретной гарнитуры выполняется на компьютере пользователя.
Отдельный `bot_bridge_adapter.py` поставляется открытым: он экспортируется в папку
вашего Discord-бота и не содержит токенов или закрытых данных приложения.

GitHub: **Actions → Windows EXE** создаёт обычную сборку без PyArmor. Скачивайте
артефакт **Krest-Windows-EXE** только из успешного запуска. Наличие скрипта сборки
не означает готовый EXE. Защищённую версию собирайте локально со своей лицензией.
Пока репозиторий публичен, исходники доступны на GitHub независимо от упаковки EXE.

## Полезные команды

Полный актуальный справочник находится в **Команды → Список команд**; кнопка
**«Все команды»** есть и на главной странице. Каталог строится из загруженных
навыков: поиск, разделы, состояние, все известные фразы и примеры, ваши синонимы,
условия работы. Выбранную фразу можно проверить без выполнения, скопировать,
добавить в избранное; весь справочник — сохранить в текстовый файл.

В **Команды → Мои команды → Свои фразы** обращение можно писать в обоих полях
или опускать. Например, **«Крест дальше» → «Крест переключи трек»**. Нажатие
«Добавить / обновить» сразу сохраняет фразу; старые записи с обращением
нормализуются при загрузке. Подстановка действует для целой фразы и не меняет
текст внутри напоминаний.

Все семь личностей имеют собственные варианты подтверждений музыкальных
действий. Реплики чередуются без немедленного повтора; сообщения об ошибках,
проценты громкости, пути скриншотов и другие важные сведения сохраняются.
В игровом режиме подтверждения переключения трека тоже учитывают личность.

В панелях Telegram и Discord доступно **98 автоответов: по 10 обычных и 4 игровых на каждую
личность**. Можно следовать личности профиля либо выбрать отдельный характер
для переписки и оформление сообщения. Предпросмотр показывает обычное, срочное,
ночное сообщение, вложение или состояние во время игры и ничего не отправляет.
Есть режим «только срочные» и сохраняемая пауза автоответов на час. Пауза применяется
к Telegram User, Discord Bot и личной Discord-сессии, даже если меню закрыто.
Боты должны быть подключены, а автоответы включены для соответствующего сервиса.

- Музыка: «переключи трек», «переключить трек», «смени песню», «поставь следующий трек»,
  «переключи на предыдущий трек». Слово «Крест» нужно перед первой командой.
- «Крест, мут», «Крест, выключи микро», «Крест, замуть меня» — выключить микрофон Discord.
- «Крест, анмут», «Крест, включи микро», «Крест, размуть меня» — включить его.
- «Крест, я в муте», «Крест, проверь микрофон» — проверить состояние без переключения.
- «Сделай скриншот», «открой скриншоты».
- «Открой сводку по миру», «скрой сводку», «что мне делать в игре» — Warframe.
- «Варфрейм план на тридцать минут», «варфрейм где фармить нейроды».
- «Запусти доту с гидом», «сводка матча», «когда руны», «убили Рошана».

Микрофон управляется через кнопку самого настольного Discord в Windows: токен,
подключение бота и Premium не требуются. Крест продолжает слышать команды; системный
микрофон не отключается. Повторное «выключи» оставляет мут включённым, повторное
«включи» оставляет микрофон включённым. Проверяется состояние кнопки, а не передача
звука собеседникам: серверный мут, отсутствие канала и режим «по нажатию» остаются
настройками Discord. Поддерживаются русские и английские названия кнопок.
Для свёрнутого/скрытого окна Крест временно показывает его без активации и возвращает
прежнее состояние. Если Discord не предоставляет доступ к кнопке, команда сообщит
об этом; откройте главное окно Discord и повторите проверку. Другие приложения
и браузерная версия Discord этим навыком не управляются.
Длинные команды с «в Дискорде» также работают; учитывается ошибка распознавания
«выключи микрофон в дс горде». Называть приложение в коротких командах необязательно.

Для музыки учитываются конкретные ошибки лёгкого Vosk: «креси с ключи трек»,
«крест прикручивать трек». Исправления действуют только на целую короткую команду;
они видны в истории распознавания и в кнопке «Разбор команды». Обычный режим Vosk
с оценкой уверенности каждого слова, модель и голос остаются прежними.
Разговорные формы работают для всего каталога: «можешь пожалуйста сделать скриншот»,
«открыть проводник», «поставить таймер на пять минут». При неизвестной фразе Крест
сравнивает слова и звучание с командами включённых навыков, включая импортированные.
Ошибки пробелов вроде «скрин шот» также учитываются. Числа и текст параметров
не подменяются похожим примером из справочника.

Однозначные исправления для ограниченного набора простых действий выполняются сразу.
В остальных случаях Крест уточняет одну команду или предлагает два варианта:
ответьте «Крест, да», «Крест, первое», «Крест, второе» либо «нет». Уточнение действует
25 секунд. Случайное «да» без обращения действие не запускает. После успешной
подтверждённой команды исправление сохраняется локально в **Дела и сценарии → Память**,
категория «Исправление»; его можно отредактировать или удалить. Для исправленных
команд закрытия, выключения, удаления и сторонних функций уточнение сохраняется.
Это обработка языка команд, а не обучение новой голосовой модели; сильный шум
и совсем другое распознанное предложение могут потребовать повторения.

При неизвестной голосовой команде
длинные подсказки остаются в меню; вслух — короткая просьба повторить не чаще раза
в десять секунд после обращения. Неизвестные фразы без обращения в окне продолжения
не озвучиваются. Во время игры успешное управление музыкой подтверждается «Готово».

Warframe определяется автоматически. Сводка появляется под игровым крестом;
для окна поверх игры используйте оконный режим без рамки. OCR распознаёт несколько
известных экранов, не противников и не весь игровой мир. Экспериментальный маршрут
записывает до минуты клавиш движения и повторяет один раз после подтверждения.
Esc, F8, движение мыши, смена окна или «верни управление» останавливают повтор.
Самостоятельный AFK-бой не реализован.

## Память экранов Warframe

Крест начинает с готовых признаков девяти экранов: завершение и провал миссии,
выбор награды реликвии, кузница, арсенал, навигация, сбой, выживание, возрождение.
Для начала распознавания не нужны часы записи. OCR проверяет активное окно
игры, а при неизвестном экране отдельно читает панель задания в верхнем левом
углу. Текст чата и исходные изображения не сохраняются этим механизмом.

В **Warframe → Обучение** видны текущее состояние зрения, число узнанных кадров,
сохранённые образцы и результаты проверок на других кадрах. Если текст не читается
или язык OCR недоступен, отображается причина. Узел, варфрейм и цель по умолчанию
не определены. Свой профиль можно указать в дополнительных настройках; Крест
не выдаёт его за распознанную экипировку.

Автоматическая память требует двух согласованных OCR-наблюдений. Сохраняется до
восьми маленьких цветовых образцов на тип экрана. Догадки самой памяти не используются
как обучающие метки и не запускают управление персонажем. Для интерфейса, который
OCR не узнаёт, можно дать один пример голосом:

- «Крест, запомни экран кузница» — подписать кадр активной игры.
- «Крест, проверь экран кузница» — проверить узнавание без дообучения на проверочном кадре.
- «Крест, проверь зрение варфрейм» — проверить захват и OCR.
- «Чему научилась в варфрейме» — отчёт под крестом.

В меню у этих проверок есть задержка пять секунд для возвращения в игру. Почти
одинаковые обучающие кадры и повторные проверки того же кадра не увеличивают счётчики.
Это небольшой классификатор знакомых интерфейсов: смена разрешения или оформления
может потребовать новых примеров. Успешное узнавание экрана не доказывает навыки боя.

Запись полных показов отделена от обычного обучения и **выключена по умолчанию**.
Её можно включить отдельно: один JPEG до 1024×576 раз в пять секунд, ограниченный
набор игровых клавиш, отрезки до 20 минут, предел автозаписей 512 МБ. Ручные записи
не удаляются автоматически. Они могут содержать видимый игровой чат. Данные остаются
в `warframe_training/` и `warframe_visual_memory.json` в папке данных Крест.

Для целей доступна команда «варфрейм прогресс реликвии акси всего три»: задаётся
общее количество по существующей цели, подтверждённое вами. Повтор команды не
удваивает награду. Количество добычи не выводится из похожего кадра.

Автономный запуск миссии, поиск демолиста, бой и эвакуация не обучены. Крест не
обещает самостоятельный AFK-фарм на основании количества записанных кадров.

## Боты и данные

**Discord · мой аккаунт** — токен личной сессии, отдельное включение автоответов
и обновления вашего статуса. **Discord · серверный бот** — Bot Token из Developer
Portal, список серверов и текстовых каналов, проверка прав, настройка активности
и отправка сообщений от имени бота. Приглашение на сервер открывается кнопкой
после подключения. Привилегированные Message Content / Members intents не нужны.
Отправка выполняется только по нажатию; при потере подтверждения проверьте канал
перед повтором. Для больших аккаунтов панель показывает первые 50 серверов и
60 доступных текстовых каналов выбранного сервера.

На вкладке серверного Discord-бота раскройте выбор скрипта и нажмите
**«Подключить папку Discord-бота / экспортировать мост…»**. Выберите каталог и
запускаемый `.py`: рядом появятся отдельные launcher, адаптер и манифест Крест.
Исходник бота сохраняется. Поддерживаются проекты на `discord.py`; собственные
обработчики бота продолжают работать, панель получает серверы, каналы и отправку
сообщений. Токен передаётся при запуске из меню, без записи в экспортируемые файлы.
Сохраните настройки и перезапустите сервис. При наличии `.venv` или `venv` в папке
используется её Python; зависимости проекта должны быть установлены в этой среде.

В Telegram Terminal откройте `/menu`: состояние ПК, музыка и микрофон Discord,
дела, игры, файлы и скриншот доступны по разделам. В панели Telegram кнопка
**«Включить базовый пульт ПК»** включает набор разрешённых действий. Пульт принимает
команды только от указанного владельца в личном чате; запрет управления при
блокировке Windows сохраняется. Файлы выдаются из `uploads` и `screenshots`.
Параметры таймера/напоминания передаются текстом с сохранением регистра.

Steam показывает инвентарь CS2 и обмены перед списком игр. Ошибка Web API Key
отделена от приватности публичного инвентаря. При 429 действует сохранённая пауза
повторных запросов, включая Telegram Terminal; прежние данные остаются видимыми.
403 требует действующего ключа или изменения приватности в Steam — Крест не
может отменить ограничение сервера. Неполученные сведения не показываются как ноль.

В полях ключей есть кнопка «Вставить», контекстное меню по правой кнопке,
Ctrl+V и Shift+Insert. Сочетания клавиш работают и в русской раскладке Windows.
Кнопка «Вставить» заменяет значение целиком, повторное нажатие не дублирует ключ.

Telegram User: введите API ID, API Hash и полный телефон с кодом страны,
нажмите «Получить код», затем введите код и нажмите «Войти». При включённой 2FA
появится отдельное окно пароля. Неверный код или пароль можно исправить без
повторного запроса кода. После успешного входа нажмите «Запустить».
Обновление описания Telegram включается отдельно; исходный текст профиля
не меняется при обычном подключении. Статус «Подключён» означает подтверждённую
готовность сервиса; работающий процесс без подключения показывает «Подключение…».

Личная сессия Discord использует неофициальные
интерфейсы; Discord запрещает self-bots, возможна блокировка. Статусы и автоответы
включаются отдельно. Telegram и Discord используют общие стили ответов с
предпросмотром, ограничением частоты и настройкой удаления. Токены вводите только
в локальном меню. В Windows используется хранилище учётных данных.

Данные EXE-версии: `%LOCALAPPDATA%\Krest\Data`. Скриншоты — подпапка `screenshots`;
в исходниках она находится рядом с `main.py` или выбранным файлом настроек.
Для выдачи Premium автору служит `tools/license_admin.py`. Приватный ключ храните
вне репозитория и сборки. `license_public_key.pem` нужен приложению для проверки.
