# Крест — голосовой помощник для Windows

Голосовые команды, управление музыкой и компьютером, напоминания, Steam,
Telegram/Discord, помощник Warframe. Боты и дополнительные темы
доступны после активации Premium в меню.

## Запуск исходников

Откройте **start.bat**. Помощник подготовит Python и зависимости, затем откроет
Крест. При первом запуске укажите имя. Микрофон подключается автоматически;
начните с «Крест, который час?».

## Обновления и меню

`start.bat` проверяет зависимости уже скачанной версии; `build-exe.bat` собирает
текущие исходники, включая новые модули и навыки. Они не скачивают код с GitHub.
Для копии через `git clone` используйте **update.bat**: завершите Крест через меню,
включая ядро в трее, и запустите файл. Обновление идёт из `origin/main`, только
вперёд и без удаления ваших правок; перед ним создаётся копия пользовательских
данных. Затем открывается запуск с проверкой зависимостей. Нужен Git for Windows.
ZIP без истории Git обновляйте новой распаковкой, сохраняя `model` и личные данные.
Готовый EXE обновляется новой ZIP-сборкой, а не батником для исходников.

Декоративные снег, кровь и частицы удалены вместе с настройками и фоновыми
таймерами. Старые параметры эффектов больше не используются. Игровой крест и
короткая подсветка кнопок сохранены. Во вкладке Premium есть **«Вставить и
активировать»**: скопируйте полный код; переносы строк убираются автоматически.

## Изменения 0.12.2 — цепочки, отмена и обратная связь

- **Несколько действий одной фразой:** «Крест, переключи трек и поставь таймер
  на две минуты». До пяти команд с «и», «затем», «а потом». Вся цепочка проверяется
  перед стартом, шаги выполняются по порядку; ошибка останавливает оставшиеся шаги.
  Музыка, системная громкость, микрофон Discord, таймеры, напоминания, скриншот,
  время, запуск программ/игр и основные сводки поддерживают цепочки. Команды
  выключения ПК, удаления и сторонние навыки нужно вызывать отдельно.
- «Купить хлеб и молоко» остаётся текстом напоминания. Если после напоминания
  или названия программы нужно выполнить другое действие, скажите **«следующая
  команда»**; при текстовом вводе можно поставить `;`. Кнопка «Разбор команды»
  показывает порядок шагов и причину, по которой цепочка не может запуститься.
- **«Крест, верни как было»** отменяет последнее поддерживаемое изменение:
  системную громкость/mute, создание/изменение/отмену таймера или будильника,
  ручную сортировку загрузок. Каждый шаг цепочки отменяется отдельно. История
  хранит до 20 действий текущего запуска за последние 30 минут. Отмена проверяет
  устройство и текущее состояние, не перезаписывает занятые файлы и не трогает
  другие таймеры. Уже сработавшие напоминания не воссоздаются.
- **Индикатор команды:** услышала обращение → распознаёт → ожидает очередь →
  выполняет → готово/ошибка. Состояния видны в игровом кресте и статусе голоса
  в меню. Ответ медленной старой команды не затирает состояние новой.
- **Продолжение недосказанной команды:** отдельные окончательные результаты
  «Крест, переключи» и «трек» объединяются без повторного обращения. Ожидание
  продолжения — 1,4 секунды, при поступлении слов не более пяти секунд суммарно.
  Готовые команды не получают этой задержки. Посторонний разговор и пропуск
  звука сбрасывают сборку фразы; промежуточные гипотезы ничего не выполняют.
- Короткий путь определения конца речи расширен на фиксированные команды из
  поддерживаемого каталога. У каждой команды в цепочке отдельно проверяется
  уверенность: хорошо услышанный первый шаг не скрывает плохо услышанный второй.
  Используются прежние лёгкие модели, без дополнительной нагрузки на GPU.

Сборка сохраняет папку `dist/Krest` и ZIP `dist/Krest-Windows-0.12.2.zip`.
Проверки включают настоящий Vosk/Silero на синтезированной речи; это не гарантирует
такое же распознавание любой гарнитуры и голоса в шумной игре.

## Изменения 0.12.1 — слух и выполнение команд

- Если Vosk уже завершила фразу, она сразу передаётся на проверку обращения,
  уверенности и команды. Это относится ко всем навыкам, включая команды с аргументами.
  Постоянный фон больше не растягивает такую фразу до двадцатисекундного ограничения.
  Промежуточные слова ничего не выполняют. Фоновый разговор без обращения не попадает
  в очередь заданий. Уверенность оценивается по обращению и команде, без разговора до них.
- Микрофон продолжает слушать во время подготовки голосового ответа. Защита от
  собственного голоса при использовании колонок включается только на воспроизведение.
  Явно названные наушники определяются по устройству вывода автоматически; если Windows
  называет их «Динамики», остаётся кнопка **«Играю в наушниках»** в настройках голоса.
- Поток распознавания использует аудиопланировщик Windows и просыпается при поступлении
  звука. Чтение каталога и обученных фраз выполняется отдельно. Буфер переживает короткую
  задержку обработки; звук старше двух секунд отбрасывается, чтобы не выполнить старую
  команду после зависания. После потери звука распознавание восстанавливается и на
  акустической границе Vosk, даже если микрофон постоянно передаёт шум.
- Первое переподключение после ошибки начинается через секунду; при повторных сбоях
  интервал увеличивается до 30 секунд. В настройках видны восстановление потока,
  режим наушников и использование аудиоприоритета.
- Команды поступают в отдельные очереди: плеер, громкость, Discord, окна/запуск, файлы,
  интернет-справки, запросы Warframe, диагностика и сторонние навыки. Медленный
  запрос погоды или сортировка не блокирует таймер, скриншот и управление музыкой.
  Очереди просыпаются по событию, а действия с одним ресурсом сохраняют порядок.
- Чтение сетевых ответов ограничено по времени и размеру; диагностика NVIDIA имеет
  таймаут 3 секунды. Очистку временных файлов можно остановить через список заданий.
  Горячие клавиши освобождают уже нажатые модификаторы при ошибке отправки.
- `main.py --check` проверяет маршрутизацию и параметры всех 189 встроенных навыков
  на 554 примерах и ключевых фразах. Проверка не выполняет действия на компьютере.

Модели Vosk и Silero сохранены, GPU не требуется. Проверка сборки прогоняет реальное
аудио с новым фоном и задержкой обработки 1,2 секунды. Она не заменяет проверку вашей
гарнитуры, драйвера и нагрузки игры.

## Изменения 0.12.0 — обращение, сообщения и Warframe

- Крест выделяет обращение внутри речи: «ребята сейчас приду крест переключи трек».
  Разговор до имени отбрасывается. Знакомое короткое управление понимается с
  «можешь сейчас пожалуйста» и пояснением «а то надоел». Отрицание, текст напоминания
  и пересказ чужой команды не вырезаются ради случайного выполнения действия.
  После действия окно без обращения закрывается. Отдельное «Крест» и F8 по-прежнему
  разрешают следующую команду без имени. Голосовая модель не заменена.
- Telegram отличает собственный автоответ от вашего сообщения, включая обновление,
  пришедшее до завершения отправки. Ошибка индикатора «печатает» больше не срывает
  ответ. Неудачная отправка освобождает паузу, ограничения Telegram/Discord учитываются.
  Пауза между ответами одному контакту сохраняется; ваш личный ответ даёт паузу 5 минут.
- Уведомление об отправителе приходит независимо от паузы автоответов. «Крест, кто
  написал?» — сводка пропущенных уведомлений; «отметь сообщения прочитанными» — очистить
  их в Крест. Чаты мессенджеров команда не меняет. Содержимое сообщений не сохраняется.
  Объявление имени в игре отключается в **Уведомлениях**, тихий режим соблюдается.
- Каталог Windows сканируется при запуске и каждые 10 минут, Steam — раз в минуту.
  **Система → Программы** показывает словарь. «Открой яндекс», «запусти варф»,
  «открой контра» привязаны к реально найденным приложениям. Неоднозначное имя
  не выбирает первое совпадение. Словарь помогает сопоставлению команд, не обучает
  акустическую модель Vosk новым словам. Игры доступны без запуска Premium Steam-бота.
- Dota-гид полностью удалён: вкладка, команды, GSI-сервер, автозапуск и настройки.
  Сама Dota остаётся обычной игрой в каталоге Steam.
- Warframe читает контрастную область задания, исключает чат из полного кадра,
  использует доступный русский язык OCR. Добавлены захват, зачистка и эвакуация;
  раунд, проводники и жизнеобеспечение подтверждаются двумя чтениями. Короткие
  предупреждения и журнал завершённых/проваленных забегов работают автоматически.
  «Крест, отчёт фарма» разворачивает сведения под крестом. Названия реликвий на
  результатах — наблюдения OCR: они не увеличивают инвентарь или цели без проверки.
  Автономный бой и прохождение миссии этим обновлением не реализованы.
- Новый бесплатный **Graphite**, Segoe UI в Windows, скруглённые контрастные кнопки.
  Прокрутка страниц использует обычные непрозрачные виджеты вместо Canvas; нет
  промежуточного масштабирования текста. Положение прокрутки сохраняется между
  вкладками. Закрытые списки и числовые поля не меняются колесом мыши.

- Помощники Windows повторно используют процесс, завершаются после двух минут

  панель пользователя. Окно из трея временно показывается позади активного окна и
  возвращается в прежнее состояние.
- **Голос → «Играю в наушниках»** сразу сохраняет режим, позволяющий говорить во
  время ответа Крест. Существующая настройка для колонок сама не меняется.
  Диагностика отдельно показывает захват звука, буфер, Vosk, паузу, очередь и действие.
- Windows-сборка проверяет поток распознавания синтезированными фразами Silero
  через настоящий Vosk, включая тихий сигнал и небольшой шум. Это проверка
  комплектных моделей, а не измерение точности на вашем микрофоне.

Команды: **«Крест, мут»**, **«Крест, включи микро»**, **«Крест, я в муте»**,
**«Крест, переключи трек»**, **«Крест, поставь лайк»**. Если Discord не предоставляет
кнопки через Windows или запущен с другими правами, Крест сообщает об этом и не
переключает микрофон вслепую. Реальное поведение клиента проверяется на вашем ПК.

## Характер и разговор

Семь личностей имеют по 69 собственных реплик для 23 ситуаций и общий набор из
20 фактов. Ответы в одной теме чередуются без повторения до конца набора.
Стиль выбирается в профиле; голосовая модель остаётся прежней, интернет не нужен.
Это локальная база диалогов, а не свободно обучающаяся разговорная модель.

Попробуйте: «Крест, я вернулся», «у меня получилось», «меня всё бесит»,
«помоги сосредоточиться», «мне нужен перерыв», «вдохнови меня», «ты классная»,
«пожелай удачи в игре», «ты меня слышишь», «спокойной ночи», «до встречи».
Разговор о перерыве или сне сам по себе не запускает таймер и не выключает ПК.

## Яндекс Музыка и другие плееры

Текущий источник выбирается по медиасессиям Windows. Пауза, продолжение,
предыдущий/следующий трек работают через медиасессию. Лайк в настольной Яндекс
Музыке и Spotify ищется через доступные элементы окна: сначала панель текущего
трека, затем её кнопка отметки. Поддержаны дополнительные названия кнопок
коллекции и идентификаторы настольного приложения. После нажатия проверяются
состояние отметки и неизменность трека; повторный лайк не должен снимать отметку.

Доступ к кнопкам выполняется в отдельном короткоживущем процессе с лимитом
ожидания 20 секунд. Зависший помощник доступа завершается отдельно от ядра.

Для лайка Крест также ищет скрытое окно плеера в трее и временно открывает его
позади других окон, не переводя фокус с игры; затем возвращает прежнее состояние.
Крест запрашивает у Electron дерево доступности без перезапуска приложения. Если приложение не
отдаёт подписи или состояние кнопок, действие завершается с объяснением:
координаты и глобальные горячие клавиши наугад не используются. «Музыка →
Проверить доступные команды и лайки → Диагностика плеера» показывает найденный
источник и кнопки, ничего не нажимая. Совместимость конкретной версии плеера
проверяется на Windows с запущенной музыкой.

## Голос: просто положите папку model рядом с программой

Поддерживаются оба варианта:

```text
Крест/
  main.py                  # или Krest.exe в готовой сборке
  model/
    am/final.mdl
    conf/model.conf
    model_silero.pt         # если есть файл голоса Silero
```

или распакованная модель внутри `model/vosk-model-small-ru-.../`. Крест ищет
модели до трёх уровней вложенности в `model`, `models`, `voice`; в EXE-версии
проверяет папку рядом с EXE независимо от рабочей папки запуска. Файлы Silero
`model_silero.pt`, `silero.pt`, `v4_ru.pt`, `v3_1_ru.pt`, `v3_ru.pt` тоже находятся
внутри `model` автоматически. Сохранённый существующий путь имеет приоритет.

Vosk распознаёт речь, Silero озвучивает ответы. Если имеется только Vosk,
распознавание может работать без озвучки. Недостающие модели при разрешённой
автозагрузке скачиваются с официальных серверов; найденная лёгкая модель не
заменяется большой. При нескольких неоднозначных моделях выберите нужную в меню.
Оборванные или повреждённые файлы Silero не считаются готовой моделью. Озвучка
восстанавливается в фоне с повторными попытками; микрофон продолжает слушать.
В разделе «Голос» видны ход загрузки и конкретная причина ошибки.

При `Failed to create a model` проверяется комплектность Vosk. Повреждённую
модель Крест пытается восстановить в отдельной папке, сохраняя ваши файлы.
Для путей с кириллицей используется короткий путь Windows, если он доступен.
При отсутствии интернета восстановление повторяется с паузой. Обычная Windows-
сборка проверяет загрузку Vosk также из папки с русским именем.

Для полностью распознанных коротких команд используется пауза от 400 мс:
словарь включает музыкальные команды, mute и ваши соответствующие синонимы.
Незавершённая гипотеза Vosk не выполняется. В разделе «Голос» есть режим
**«Я в наушниках: слышать команды во время ответа»**; включайте его при прослушивании
Крест через наушники, чтобы исключить захват её ответа через колонки.
Прослушивание работает в ядре независимо от меню. В трее есть «Возобновить
прослушивание»; устаревшая запись после длительного зависания отбрасывается.

Микрофон выбирается автоматически: сначала системный вход Windows, затем другие
доступные устройства. Крест подбирает частоту USB/Bluetooth-микрофона и переводит
звук в нужный для распознавания формат. Если вход перестал передавать данные,
Крест пробует следующий. При тишине из-за mute она показывает подсказку.
Кнопка **«Автоматически подключить микрофон»** сбрасывает старый выбор устройства,
включает адаптацию чувствительности и перезапускает подключение. Если Windows
запретила микрофон, кнопка рядом открывает параметры доступа для классических приложений.

## Собрать программу в EXE

**Дважды нажмите build-exe.bat.** На компьютере автора нужен Python 3.11/3.12 x64;
если его нет, сначала откройте `start.bat`. Скрипт создаёт отдельную среду сборки,
устанавливает CPU-зависимости и упаковывает приложение через PyInstaller.
Visual Studio, Nuitka и Inno Setup не требуются.

Результат: **dist/Krest/Krest.exe** и **dist/Krest-Windows-0.12.2.zip**.
Передавайте пользователю ZIP целиком. Каталог `_internal` содержит необходимые
библиотеки: его нельзя удалять или отделять от EXE. **Модели Vosk и Silero входят
в обычную сборку автоматически**, в папку `model` рядом с EXE. Отсутствующие модели
скачиваются при сборке; если подготовка или синтез не удались, новый ZIP не создаётся.
Пользователю Python и загрузка моделей для этой сборки не нужны. Архив нужно сначала
полностью распаковать, затем запускать `Krest.exe` из распакованной папки.
Предыдущая сборка при повторном запуске сохраняется в `dist/Krest-previous-*`.

Дополнительные параметры для автора:

```bat
build-exe.bat --protect
build-exe.bat --protect --license "C:\путь\лицензия-pyarmor.zip"
build-exe.bat --without-models
```

Старый параметр `--with-models` поддерживается, но больше не требуется.
`--without-models` создаёт специальный облегчённый ZIP с пометкой `online-setup`:
ему нужен интернет при первом запуске. Для передачи друзьям используйте обычную сборку.

Обычный режим прячет Python-модули внутри пакета, но **байткод можно извлечь**.
`--protect` применяет PyArmor: собственный код обфусцируется и выполняется через
защитный runtime. Это затрудняет анализ, но не гарантирует полной секретности.
Для размера этого проекта может понадобиться лицензия PyArmor; при ограничении
лицензии или ошибке защиты сборка прекращается без незащищённой подмены.
PyTorch и прочие сторонние библиотеки упаковываются в готовом виде.

В сборку не копируются тесты, отчёты, Git, основные исходники проекта в виде открытых `.py`,
пользовательские настройки, сессии ботов и приватные ключи. После упаковки автоматически
проверяются загрузка команд, отдельный процесс ядра, импорт голосовых/сервисных
библиотек и настоящий синтез Silero с загрузкой Vosk. Проверка моделей запускается
из чистого профиля без их скачивания. Она не отправляет сообщения и не обращается
к микрофону или динамикам; проверка конкретной гарнитуры выполняется на компьютере пользователя.
Отдельный `bot_bridge_adapter.py` поставляется открытым: он экспортируется в папку
вашего Discord-бота и не содержит токенов или закрытых данных приложения.

GitHub: **Actions → Windows EXE** создаёт обычную сборку без PyArmor. Скачивайте
артефакт **Krest-Windows-EXE** только из успешного запуска. Наличие скрипта сборки
не означает готовый EXE. Защищённую версию собирайте локально со своей лицензией.
Пока репозиторий публичен, исходники доступны на GitHub независимо от упаковки EXE.

## Полезные команды

Полный актуальный справочник находится в **Команды → Список команд**; кнопка
**«Все команды»** есть и на главной странице. Каталог строится из загруженных
навыков: поиск, разделы, состояние, все известные фразы и примеры, ваши синонимы,
условия работы. Выбранную фразу можно проверить без выполнения, скопировать,
добавить в избранное; весь справочник — сохранить в текстовый файл.

В **Команды → Мои команды → Свои фразы** обращение можно писать в обоих полях
или опускать. Например, **«Крест дальше» → «Крест переключи трек»**. Нажатие
«Добавить / обновить» сразу сохраняет фразу; старые записи с обращением
нормализуются при загрузке. Подстановка действует для целой фразы и не меняет
текст внутри напоминаний.

Все семь личностей имеют собственные варианты подтверждений музыкальных
действий. Реплики чередуются без немедленного повтора; сообщения об ошибках,
проценты громкости, пути скриншотов и другие важные сведения сохраняются.
В игровом режиме подтверждения переключения трека тоже учитывают личность.

В панелях Telegram и Discord доступно **42 автоответа: по шесть на каждую
личность**. Можно следовать личности профиля либо выбрать отдельный характер
для переписки и оформление сообщения. Предпросмотр показывает обычное, срочное,
ночное сообщение, вложение или состояние во время игры и ничего не отправляет.
Есть режим «только срочные» и сохраняемая пауза автоответов на час. Пауза применяется
к Telegram User, Discord Bot и личной Discord-сессии, даже если меню закрыто.
Боты должны быть подключены, а автоответы включены для соответствующего сервиса.

- Музыка: «переключи трек», «переключить трек», «смени песню», «поставь следующий трек»,
  «переключи на предыдущий трек». Слово «Крест» нужно перед первой командой.
- «Крест, мут», «Крест, выключи микро», «Крест, замуть меня» — выключить микрофон Discord.
- «Крест, анмут», «Крест, включи микро», «Крест, размуть меня» — включить его.
- «Крест, я в муте», «Крест, проверь микрофон» — проверить состояние без переключения.
- «Сделай скриншот», «открой скриншоты».
- «Открой сводку по миру», «скрой сводку», «что мне делать в игре» — Warframe.
- «Варфрейм план на тридцать минут», «варфрейм где фармить нейроды».
- «Запусти доту с гидом», «сводка матча», «когда руны», «убили Рошана».

Микрофон управляется через кнопку самого настольного Discord в Windows: токен,
подключение бота и Premium не требуются. Крест продолжает слышать команды; системный
микрофон не отключается. Повторное «выключи» оставляет мут включённым, повторное
«включи» оставляет микрофон включённым. Проверяется состояние кнопки, а не передача
звука собеседникам: серверный мут, отсутствие канала и режим «по нажатию» остаются
настройками Discord. Поддерживаются русские и английские названия кнопок.
Для свёрнутого/скрытого окна Крест временно показывает его без активации и возвращает
прежнее состояние. Если Discord не предоставляет доступ к кнопке, команда сообщит
об этом; откройте главное окно Discord и повторите проверку. Другие приложения
и браузерная версия Discord этим навыком не управляются.
Длинные команды с «в Дискорде» также работают; учитывается ошибка распознавания
«выключи микрофон в дс горде». Называть приложение в коротких командах необязательно.

Для музыки учитываются конкретные ошибки лёгкого Vosk: «креси с ключи трек»,
«крест прикручивать трек». Исправления действуют только на целую короткую команду;
они видны в истории распознавания и в кнопке «Разбор команды». Обычный режим Vosk
с оценкой уверенности каждого слова, модель и голос остаются прежними.
Разговорные формы работают для всего каталога: «можешь пожалуйста сделать скриншот»,
«открыть проводник», «поставить таймер на пять минут». При неизвестной фразе Крест
сравнивает слова и звучание с командами включённых навыков, включая импортированные.
Ошибки пробелов вроде «скрин шот» также учитываются. Числа и текст параметров
не подменяются похожим примером из справочника.

Однозначные исправления для ограниченного набора простых действий выполняются сразу.
В остальных случаях Крест уточняет одну команду или предлагает два варианта:
ответьте «Крест, да», «Крест, первое», «Крест, второе» либо «нет». Уточнение действует
25 секунд. Случайное «да» без обращения действие не запускает. После успешной
подтверждённой команды исправление сохраняется локально в **Дела и сценарии → Память**,
категория «Исправление»; его можно отредактировать или удалить. Для исправленных
команд закрытия, выключения, удаления и сторонних функций уточнение сохраняется.
Это обработка языка команд, а не обучение новой голосовой модели; сильный шум
и совсем другое распознанное предложение могут потребовать повторения.

При неизвестной голосовой команде
длинные подсказки остаются в меню; вслух — короткая просьба повторить не чаще раза
в десять секунд после обращения. Неизвестные фразы без обращения в окне продолжения
не озвучиваются. Во время игры успешное управление музыкой подтверждается «Готово».

Warframe определяется автоматически. Сводка появляется под игровым крестом;
для окна поверх игры используйте оконный режим без рамки. OCR распознаёт несколько
известных экранов, не противников и не весь игровой мир. Экспериментальный маршрут
записывает до минуты клавиш движения и повторяет один раз после подтверждения.
Esc, F8, движение мыши, смена окна или «верни управление» останавливают повтор.
Самостоятельный AFK-бой не реализован.

## Память экранов Warframe

Крест начинает с готовых признаков девяти экранов: завершение и провал миссии,
выбор награды реликвии, кузница, арсенал, навигация, сбой, выживание, возрождение.
Для начала распознавания не нужны часы записи. OCR проверяет активное окно
игры, а при неизвестном экране отдельно читает панель задания в верхнем левом
углу. Текст чата и исходные изображения не сохраняются этим механизмом.

В **Warframe → Обучение** видны текущее состояние зрения, число узнанных кадров,
сохранённые образцы и результаты проверок на других кадрах. Если текст не читается
или язык OCR недоступен, отображается причина. Узел, варфрейм и цель по умолчанию
не определены. Свой профиль можно указать в дополнительных настройках; Крест
не выдаёт его за распознанную экипировку.

Автоматическая память требует двух согласованных OCR-наблюдений. Сохраняется до
восьми маленьких цветовых образцов на тип экрана. Догадки самой памяти не используются
как обучающие метки и не запускают управление персонажем. Для интерфейса, который
OCR не узнаёт, можно дать один пример голосом:

- «Крест, запомни экран кузница» — подписать кадр активной игры.
- «Крест, проверь экран кузница» — проверить узнавание без дообучения на проверочном кадре.
- «Крест, проверь зрение варфрейм» — проверить захват и OCR.
- «Чему научилась в варфрейме» — отчёт под крестом.

В меню у этих проверок есть задержка пять секунд для возвращения в игру. Почти
одинаковые обучающие кадры и повторные проверки того же кадра не увеличивают счётчики.
Это небольшой классификатор знакомых интерфейсов: смена разрешения или оформления
может потребовать новых примеров. Успешное узнавание экрана не доказывает навыки боя.

Запись полных показов отделена от обычного обучения и **выключена по умолчанию**.
Её можно включить отдельно: один JPEG до 1024×576 раз в пять секунд, ограниченный
набор игровых клавиш, отрезки до 20 минут, предел автозаписей 512 МБ. Ручные записи
не удаляются автоматически. Они могут содержать видимый игровой чат. Данные остаются
в `warframe_training/` и `warframe_visual_memory.json` в папке данных Крест.

Для целей доступна команда «варфрейм прогресс реликвии акси всего три»: задаётся
общее количество по существующей цели, подтверждённое вами. Повтор команды не
удваивает награду. Количество добычи не выводится из похожего кадра.

Автономный запуск миссии, поиск демолиста, бой и эвакуация не обучены. Крест не
обещает самостоятельный AFK-фарм на основании количества записанных кадров.

## Боты и данные

**Discord · мой аккаунт** — токен личной сессии, отдельное включение автоответов
и обновления вашего статуса. **Discord · серверный бот** — Bot Token из Developer
Portal, список серверов и текстовых каналов, проверка прав, настройка активности
и отправка сообщений от имени бота. Приглашение на сервер открывается кнопкой
после подключения. Привилегированные Message Content / Members intents не нужны.
Отправка выполняется только по нажатию; при потере подтверждения проверьте канал
перед повтором. Для больших аккаунтов панель показывает первые 50 серверов и
60 доступных текстовых каналов выбранного сервера.

На вкладке серверного Discord-бота раскройте выбор скрипта и нажмите
**«Подключить папку Discord-бота / экспортировать мост…»**. Выберите каталог и
запускаемый `.py`: рядом появятся отдельные launcher, адаптер и манифест Крест.
Исходник бота сохраняется. Поддерживаются проекты на `discord.py`; собственные
обработчики бота продолжают работать, панель получает серверы, каналы и отправку
сообщений. Токен передаётся при запуске из меню, без записи в экспортируемые файлы.
Сохраните настройки и перезапустите сервис. При наличии `.venv` или `venv` в папке
используется её Python; зависимости проекта должны быть установлены в этой среде.

В Telegram Terminal откройте `/menu`: состояние ПК, музыка и микрофон Discord,
дела, игры, файлы и скриншот доступны по разделам. В панели Telegram кнопка
**«Включить базовый пульт ПК»** включает набор разрешённых действий. Пульт принимает
команды только от указанного владельца в личном чате; запрет управления при
блокировке Windows сохраняется. Файлы выдаются из `uploads` и `screenshots`.
Параметры таймера/напоминания передаются текстом с сохранением регистра.

Steam показывает инвентарь CS2 и обмены перед списком игр. Ошибка Web API Key
отделена от приватности публичного инвентаря. При 429 действует сохранённая пауза
повторных запросов, включая Telegram Terminal; прежние данные остаются видимыми.
403 требует действующего ключа или изменения приватности в Steam — Крест не
может отменить ограничение сервера. Неполученные сведения не показываются как ноль.

В полях ключей есть кнопка «Вставить», контекстное меню по правой кнопке,
Ctrl+V и Shift+Insert. Сочетания клавиш работают и в русской раскладке Windows.
Кнопка «Вставить» заменяет значение целиком, повторное нажатие не дублирует ключ.

Telegram User: введите API ID, API Hash и полный телефон с кодом страны,
нажмите «Получить код», затем введите код и нажмите «Войти». При включённой 2FA
появится отдельное окно пароля. Неверный код или пароль можно исправить без
повторного запроса кода. После успешного входа нажмите «Запустить».
Обновление описания Telegram включается отдельно; исходный текст профиля
не меняется при обычном подключении. Статус «Подключён» означает подтверждённую
готовность сервиса; работающий процесс без подключения показывает «Подключение…».

Личная сессия Discord использует неофициальные
интерфейсы; Discord запрещает self-bots, возможна блокировка. Статусы и автоответы
включаются отдельно. Telegram и Discord используют общие стили ответов с
предпросмотром, ограничением частоты и настройкой удаления. Токены вводите только
в локальном меню. В Windows используется хранилище учётных данных.

Данные EXE-версии: `%LOCALAPPDATA%\Krest\Data`. Скриншоты — подпапка `screenshots`;
в исходниках она находится рядом с `main.py` или выбранным файлом настроек.
Для выдачи Premium автору служит `tools/license_admin.py`. Приватный ключ храните
вне репозитория и сборки. `license_public_key.pem` нужен приложению для проверки.
